# P20 材料详情 · 来源与引用

版本 v0.3；路由 `#resource`。

## 目的与入口

看懂文件从哪里来、在哪些研究工作中使用。

入口：材料列表、导图文件链接。

依据：数据库补充 + 来源可见需求。本轮菜单/窗口定义见 `../02_INTERACTION_CONTRACTS.md`，与早期原型描述不同处以本轮为准。

## 页面组成

- 标题、文件、作者/来源信息。
- 版本、说明 MD、引用聊天和导图节点。
- 打开、编辑元数据和附加说明。

## 用户操作与结果

- 编辑来源信息与标签。
- 打开原件或说明，查看版本变化。
- 把准确片段或文件附加到输入框。

## 状态

- 元数据完整
- 来源待补充
- 多版本

## 验收

- 来源字段来自用户/文件/检索结果并注明。
- 引用入口保留项目与版本关系。

## 开发接入

首先检查完整 DSH 已有的对应组件和服务。原型的入口和结果作为功能依据，数据保存、模型调用及操作系统能力接入真实应用。未配置/不可用时用具体状态反馈，保持其他功能可用。
