# P29 添加服务 · API 表单

版本 v0.3；路由 `#provider`。

## 目的与入口

用一个表单完成服务地址、协议、凭证和模型。

入口：模型与 API 添加服务。

依据：API 接入要求补充。本轮菜单/窗口定义见 `../02_INTERACTION_CONTRACTS.md`，与早期原型描述不同处以本轮为准。

## 页面组成

- 显示名称、Base URL、协议、API Key。
- 模型发现或模型 ID。
- 可折叠高级参数。

## 用户操作与结果

- 输入配置，发现或手填模型。
- 测试配置，保存，返回服务列表。
- 更新已存服务时显示影响的角色默认值。

## 状态

- 新建
- 发现中
- 发现失败
- 保存完成

## 验收

- 错误落在对应字段并保留非敏感草稿。
- 保存后模型选择器出现该模型。

## 开发接入

首先检查完整 DSH 已有的对应组件和服务。原型的入口和结果作为功能依据，数据保存、模型调用及操作系统能力接入真实应用。未配置/不可用时用具体状态反馈，保持其他功能可用。
