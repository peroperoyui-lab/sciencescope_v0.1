# P40 环境配置 · 便携目录

版本 v0.3；路由 `#environment`。

## 目的与入口

让用户知道软件自己的文件和执行环境在哪里。

入口：设置环境配置。

依据：最新安装目录要求 + 完整 DSH 路线。本轮菜单/窗口定义见 `../02_INTERACTION_CONTRACTS.md`，与早期原型描述不同处以本轮为准。

## 页面组成

- 安装目录、运行数据、项目、模型配置、浏览器数据、缓存。
- DSH 和所需工具就绪状态。
- 自身 skills 与外部 skills 引用。

## 用户操作与结果

- 一键打开各目录并导出诊断。
- 检查路径可写，必要时选择用户授权的新目录。
- 读取外部 Codex/Claude skills 时显示来源，自身安装位置保持独立。

## 状态

- 本地就绪
- 目录不可写
- 工具未安装
- 外部技能可读取

## 验收

- 迁移安装目录后可找到自身项目和配置。
- UI 显示实际路径，不伪造环境检测通过。

## 开发接入

首先检查完整 DSH 已有的对应组件和服务。原型的入口和结果作为功能依据，数据保存、模型调用及操作系统能力接入真实应用。未配置/不可用时用具体状态反馈，保持其他功能可用。
