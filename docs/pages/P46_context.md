# P46 引用与批注

版本 v0.3；路由 `#context`。

## 目的与入口

检查附带到本次发送的材料与临时批注，独立于模型 Token 状态。

入口：输入框加号菜单、批注标签。

依据：PPT 输入框加号 + 用户上下文目标。本轮菜单/窗口定义见 `../02_INTERACTION_CONTRACTS.md`，与早期原型描述不同处以本轮为准。

## 页面组成

- 已选择上下文来源。
- 临时标记及附加说明。

## 用户操作与结果

- 按需勾选当前请求的内容。
- 查看来自哪个版本与更新时间。
- 把秘书组织的正文与引用一起送出。

## 状态

- 无额外引用
- 多版本引用
- 引用内容已更新

## 验收

- 旧材料仍能追溯但当前采用项清楚。
- 不会把累计 Token 当成本次上下文。

## 开发接入

首先检查完整 DSH 已有的对应组件和服务。原型的入口和结果作为功能依据，数据保存、模型调用及操作系统能力接入真实应用。未配置/不可用时用具体状态反馈，保持其他功能可用。
