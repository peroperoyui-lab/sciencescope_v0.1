# P41 插件与技能

版本 v0.3；路由 `#plugins`。

## 目的与入口

让用户添加可用工具和科研能力。

入口：设置插件。

依据：PPT 6 页插件 + DSH 复用方向。本轮菜单/窗口定义见 `../02_INTERACTION_CONTRACTS.md`，与早期原型描述不同处以本轮为准。

## 页面组成

- 已安装、可添加、技能目录。
- 名称、来源、版本、状态。
- 启停、设置、查看说明。

## 用户操作与结果

- 复用完整 DSH 现成插件入口。
- 添加工具，显示发现的能力和所需配置。
- 打开自身技能目录、引用外部技能。

## 状态

- 已启用
- 待配置
- 加载失败
- 有更新

## 验收

- 插件入口显示实际安装状态。
- 同一工具对专家提供共同能力。

## 开发接入

首先检查完整 DSH 已有的对应组件和服务。原型的入口和结果作为功能依据，数据保存、模型调用及操作系统能力接入真实应用。未配置/不可用时用具体状态反馈，保持其他功能可用。
