# P02 主工作聊天

版本 v0.3；路由 `#work`。

## 目的与入口

用户与专家围绕材料讨论、行动、纠偏，执行过程可见。

入口：项目树中的聊天；首页提交任务。

依据：PPT 3 页 + 最新协作要求。本轮菜单/窗口定义见 `../02_INTERACTION_CONTRACTS.md`，与早期原型描述不同处以本轮为准。

## 页面组成

- 主区消息和工具活动。
- 底部工作/自由讨论/有序讨论、秘书总结、分支工作。
- 独立的输入草稿、模型菜单和上下文引用。

## 用户操作与结果

- 用户消息右对齐，显示日期、时间和消息操作。
- 复制消息、引用到输入框、从选中消息前缀开始分支。
- Ctrl F 查找当前对话；Ctrl K 搜索项目、对话和操作。
- 输入框圆环悬停显示模型上下文和缓存，引用及批注另设入口。
- 项目摘要在右上角浮出；浏览器/秘书侧栏仍可独立操作。

## 状态

- 空聊天
- 执行中
- 待用户决定
- 完成
- 失败或已停止

## 验收

- 切页面再返回保留输入和活动状态。
- 模型文字计划与实际工具活动分别显示。

## 开发接入

首先检查完整 DSH 已有的对应组件和服务。原型的入口和结果作为功能依据，数据保存、模型调用及操作系统能力接入真实应用。未配置/不可用时用具体状态反馈，保持其他功能可用。
