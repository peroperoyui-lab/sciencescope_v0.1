# P07 项目置顶摘要

版本 v0.3；路由 `#overview`。

## 目的与入口

在工作现场快速了解项目状态和每次细微变化。

入口：项目聊天右上置顶摘要。

依据：PPT 3 页置顶摘要 + 用户修改记录要求。本轮菜单/窗口定义见 `../02_INTERACTION_CONTRACTS.md`，与早期原型描述不同处以本轮为准。

## 页面组成

- 主聊天右上角锚定浮层，柔和底色、轻阴影。
- 项目名称、修改列表、最近日志、来源、秘书与工作站入口。

## 用户操作与结果

- 点击摘要按钮展开；关闭键、Esc 或外部点击收起。
- 浏览器打开时摘要按钮仍在，摘要可以叠在侧栏上。
- 点击文件查看预览；查看全部修改进入 P49。

## 状态

- 暂无修改
- 有新修改
- 文件已删除
- 记录来自外部编辑

## 验收

- 没有全屏遮罩或主工作区锁定。
- 不与左侧手动置顶混淆。

## 开发接入

首先检查完整 DSH 已有的对应组件和服务。原型的入口和结果作为功能依据，数据保存、模型调用及操作系统能力接入真实应用。未配置/不可用时用具体状态反馈，保持其他功能可用。
