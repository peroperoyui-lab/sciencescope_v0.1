# P43 帮助与页面导航

版本 v0.3；路由 `#help`。

## 目的与入口

查找功能说明和所有页面。

入口：顶部帮助与说明；设计包页面目录。

依据：PPT 顶部帮助与说明；补充完整页面索引。本轮菜单/窗口定义见 `../02_INTERACTION_CONTRACTS.md`，与早期原型描述不同处以本轮为准。

## 页面组成

- 搜索帮助、使用路径。
- 按功能分组的页面索引。
- 版本/来源说明与导出。

## 用户操作与结果

- 查找一个页面并直接打开。
- 打开逐页开发说明。
- 导出原型数据、重置示例。

## 状态

- 初次查看
- 搜索结果

## 验收

- 全部页面可从目录访问。
- 示例数据和真实执行的边界在原型中可见。

## 开发接入

首先检查完整 DSH 已有的对应组件和服务。原型的入口和结果作为功能依据，数据保存、模型调用及操作系统能力接入真实应用。未配置/不可用时用具体状态反馈，保持其他功能可用。
