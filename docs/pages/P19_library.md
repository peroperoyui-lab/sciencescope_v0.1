# P19 数据库 · 我的资料

版本 v0.3；路由 `#library`。

## 目的与入口

保存可复用的论文、标准和笔记，并送入项目。

入口：数据库我的资料页签。

依据：数据库未定部分的补充设计。本轮菜单/窗口定义见 `../02_INTERACTION_CONTRACTS.md`，与早期原型描述不同处以本轮为准。

## 页面组成

- 集合与标签。
- 资料列表、搜索和来源。
- 添加到项目、默认应用打开。

## 用户操作与结果

- 创建集合、增删标签、导入资料。
- 选择资料加入当前或其他项目。
- 按标题、标签、原始来源查找。

## 状态

- 空集合
- 多项目引用
- 文件待补齐

## 验收

- 资料能从集合加入项目并回到来源。
- 各级 Agent 可通过正常工具阅读和管理资料。

## 开发接入

首先检查完整 DSH 已有的对应组件和服务。原型的入口和结果作为功能依据，数据保存、模型调用及操作系统能力接入真实应用。未配置/不可用时用具体状态反馈，保持其他功能可用。
