# P16 导图内容块 · Markdown 与图片

版本 v0.3；路由 `#map-rich`。

## 目的与入口

将文字、Markdown 和图片直接放入准确的节点输入框。

入口：导图二级窗口选中研究设计/技术路线内容块。

依据：最新要求 2③。本轮菜单/窗口定义见 `../02_INTERACTION_CONTRACTS.md`，与早期原型描述不同处以本轮为准。

## 页面组成

- 当前节点的 Markdown 输入与渲染。
- 右键菜单和附件缩略图。
- 缩略图最大宽高设置。
- 同级/子级和排列操作。

## 用户操作与结果

- 右键插入文件、拖入对应框、粘贴图片。
- Markdown 文件作为可编辑内容；图片形成引用附件。
- 保持纵横比适配缩略图最大值，点击查看原图。
- Shift+Enter 在当前块换行；Tab 添加子级；多文件按顺序放入。

## 状态

- 正文编辑
- 图片加载
- 多图
- 超大图片
- 格式读取失败

## 验收

- 插入内容归属当前目标框。
- 完整内容保留，缩略图尺寸限制只改变展示。

## 开发接入

首先检查完整 DSH 已有的对应组件和服务。原型的入口和结果作为功能依据，数据保存、模型调用及操作系统能力接入真实应用。未配置/不可用时用具体状态反馈，保持其他功能可用。
