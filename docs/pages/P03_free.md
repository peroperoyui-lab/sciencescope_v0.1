# P03 自由讨论 · 多专家

版本 v0.3；路由 `#free`。

## 目的与入口

让多个 AI 从不同角度回答，用户决定如何采纳。

入口：输入框协作方式选择自由讨论。

依据：PPT 3 页。本轮菜单/窗口定义见 `../02_INTERACTION_CONTRACTS.md`，与早期原型描述不同处以本轮为准。

## 页面组成

- 参与者条带、邀请菜单、当前议题。
- 按实际作者显示回复；每位专家的子代理活动归属可见。
- 用户输入及继续讨论按钮。

## 用户操作与结果

- @ 一位或多位专家；共享本次选定议题和相关材料。
- 用户可随时补问、继续邀请、请求秘书整理。
- 展开专家当前任务与唯一子代理槽。
- 采纳意见后用正常工作消息继续，秘书更新项目说明。

## 状态

- 未选参与者
- 专家回复中
- 部分回复失败
- 待用户继续

## 验收

- 两位专家实际作者清楚。
- 专家使用共同可用工具，以角色提示形成分工。

## 开发接入

首先检查完整 DSH 已有的对应组件和服务。原型的入口和结果作为功能依据，数据保存、模型调用及操作系统能力接入真实应用。未配置/不可用时用具体状态反馈，保持其他功能可用。
