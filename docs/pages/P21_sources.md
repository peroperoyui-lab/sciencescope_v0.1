# P21 外部资源 · 学术站点

版本 v0.3；路由 `#sources`。

## 目的与入口

管理常用学术站点、已安装检索连接和导入入口。

入口：数据库外部资源；首页站点管理。

依据：PPT 1—2 页站点 + 数据库补充。本轮菜单/窗口定义见 `../02_INTERACTION_CONTRACTS.md`，与早期原型描述不同处以本轮为准。

## 页面组成

- 站点卡片、分组、搜索。
- 网址、网页登录状态、工具连接状态。
- 新增和编辑链接。

## 用户操作与结果

- 增删改排序站点，点击打开内置浏览器。
- 有连接工具时直接检索并导入材料。
- 打开与当前研究相关的网页或全文。

## 状态

- 仅书签
- 浏览器已登录
- 工具可用
- 连接异常

## 验收

- 添加站点后首页同步更新。
- 页面访问与工具可调用状态分别可见。

## 开发接入

首先检查完整 DSH 已有的对应组件和服务。原型的入口和结果作为功能依据，数据保存、模型调用及操作系统能力接入真实应用。未配置/不可用时用具体状态反馈，保持其他功能可用。
