# P28 模型与 API · 服务列表

版本 v0.3；路由 `#models`。

## 目的与入口

用户自己添加模型并给各角色选择。

入口：模型菜单加号；设置底部 API Key 服务。

依据：PPT 2 页模型菜单 / 6 页 API Key 服务。本轮菜单/窗口定义见 `../02_INTERACTION_CONTRACTS.md`，与早期原型描述不同处以本轮为准。

## 页面组成

- 服务商列表、模型列表、连接状态。
- 添加服务、测试、启停与默认模型。
- 下一次使用的模型提示。

## 用户操作与结果

- 添加自定义或现有服务，配置凭证和协议。
- 发现模型或手动添加，进入模型选择菜单。
- 测试连接；按错误提示调整。

## 状态

- 无模型
- 已保存
- 未测试
- 可连接
- 连接失败

## 验收

- 发现失败时仍能手动配置。
- 示例界面不使用真实凭证。

## 开发接入

首先检查完整 DSH 已有的对应组件和服务。原型的入口和结果作为功能依据，数据保存、模型调用及操作系统能力接入真实应用。未配置/不可用时用具体状态反馈，保持其他功能可用。
