# P05 会议秘书 · 侧栏

版本 v0.3；路由 `#secretary`。

## 目的与入口

用户私下理解材料、组织工作，秘书持续整理项目。

入口：右上书本；文件批注中的先问秘书。

依据：PPT 2—3 页 + 批注与秘书要求。本轮菜单/窗口定义见 `../02_INTERACTION_CONTRACTS.md`，与早期原型描述不同处以本轮为准。

## 页面组成

- 正式主工作区保留，右侧打开秘书面板。
- 临时提问/项目总结/导图联动入口。
- 带文件版本来源的选段与独立输入框。

## 用户操作与结果

- 将选中批注发送秘书，原批注留在待发送集合。
- 秘书解释、比较当前版本和上下文，整理下一步。
- 点击组织提示词或调用 writeandsend 出现可编辑草稿。
- 项目总结可打开关联 Markdown，导图入口跳转相应节点。

## 状态

- 无私下问题
- 正在回答
- 有待发送批注
- 总结待更新

## 验收

- 问秘书后批注数量与正式版本记录不变。
- 秘书可管理文件、版本说明和导图。

## 开发接入

首先检查完整 DSH 已有的对应组件和服务。原型的入口和结果作为功能依据，数据保存、模型调用及操作系统能力接入真实应用。未配置/不可用时用具体状态反馈，保持其他功能可用。
