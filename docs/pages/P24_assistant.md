# P24 全局助手

版本 v0.3；路由 `#assistant`。

## 目的与入口

跨项目找工作、找文件、记计划，并提供快速对话。

入口：左下全局助手；可选桌面浮球。

依据：PPT 3 页左侧浮窗。本轮菜单/窗口定义见 `../02_INTERACTION_CONTRACTS.md`，与早期原型描述不同处以本轮为准。

## 页面组成

- 独立于主窗口的浮窗。
- 球状入口/对话面板两种状态。

## 用户操作与结果

- 球与面板切换保留临时内容。
- 项目、工作站、数据库动作激活主窗口定位。
- 浏览器原型演示真实辅助窗口；原生 always-on-top/贴边由桌面接入。

## 状态

- 收起
- 展开
- 当前项目
- 跨项目查找

## 验收

- 主窗口无模态遮罩。
- 用户可同时操作主界面。

## 开发接入

首先检查完整 DSH 已有的对应组件和服务。原型的入口和结果作为功能依据，数据保存、模型调用及操作系统能力接入真实应用。未配置/不可用时用具体状态反馈，保持其他功能可用。
