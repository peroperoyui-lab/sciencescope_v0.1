# P01 开始与继续

版本 v0.3；路由 `#home`。

## 目的与入口

让用户进入后立即开始讨论或继续已有工作。

入口：应用启动；点击左上 Logo。

依据：PPT 1—2 页。本轮菜单/窗口定义见 `../02_INTERACTION_CONTRACTS.md`，与早期原型描述不同处以本轮为准。

## 页面组成

- 保留顶部菜单、左侧三个一级入口、置顶与项目聊天树。
- 中央欢迎语、最近工作、可管理学术站点；输入框位于底部。
- 右上浏览器与秘书入口；项目内出现置顶摘要按钮。

## 用户操作与结果

- 最近工作按真实项目和对话身份打开。
- 常用站点通过浏览器侧栏打开，菜单管理站点。
- 输入框支持附件和模型/运行方式菜单。
- 顶部按钮使用下拉菜单；全局助手打开独立窗口。

## 状态

- 首次使用
- 已有项目
- 未配置模型
- 最近工作为空

## 验收

- 从首页找到 API 入口并创建第一条工作。
- 站点与最近工作有实际可达的目标。

## 开发接入

首先检查完整 DSH 已有的对应组件和服务。原型的入口和结果作为功能依据，数据保存、模型调用及操作系统能力接入真实应用。未配置/不可用时用具体状态反馈，保持其他功能可用。
