# P18 数据库 · 项目材料

版本 v0.3；路由 `#database`。

## 目的与入口

统一查找当前项目材料、来源和处理情况。

入口：左侧数据库。

依据：PPT 5 页留白的补充设计。本轮菜单/窗口定义见 `../02_INTERACTION_CONTRACTS.md`，与早期原型描述不同处以本轮为准。

## 页面组成

- 当前项目材料/我的资料/外部资源页签。
- 搜索、类型筛选、列表与导入。
- 材料名称、来源、版本及处理状态。

## 用户操作与结果

- 导入、查找、筛选、打开、引用到聊天。
- 打开材料详情查看来源与被使用情况。
- 将材料加入文献版本管理或绑定导图。

## 状态

- 无材料
- 有原件
- 文本已可读
- 解析或索引处理中

## 验收

- 数据库与项目文件/文献版本引用同一材料。
- 处理状态与实际能力对应。

## 开发接入

首先检查完整 DSH 已有的对应组件和服务。原型的入口和结果作为功能依据，数据保存、模型调用及操作系统能力接入真实应用。未配置/不可用时用具体状态反馈，保持其他功能可用。
