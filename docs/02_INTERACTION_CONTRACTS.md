# 交互说明：菜单、浮层、侧栏与独立窗口

版本：v0.3 / 2026-09-17。适用于本轮原型及本地 Codex 开发。保留用户认可的浅灰白、低饱和绿和原 Logo。

## 设计标准：说明性文字用"i"提示（用户 2026-09-25）

- 页面上只直接显示名称、数值、状态、错误和需要用户处理的警告。解释"是什么、为什么、会怎样"的说明文字不写在页面正文里，
  而是放在它所说明的标题、字段标签或选项末尾的一个小"i"后面（`desktop/info-tip.mjs` 的 `infoTip()`，所有页面共用同一外观）。
- 交互：悬停或键盘聚焦时预览；点击后固定显示，再点一次、点击别处、按 Esc 或滚动时关闭。点击选项或菜单项里的"i"只显示说明，不会选中该项。
- 不属于"说明"、仍然直接显示的：校验错误和警告、运行状态、空状态文字、尚未开放功能的状态说明（例如"此设置尚未开放"）、路径和版本等数据。
- 已批准原型自带的文字（例如欢迎页、创建项目页底部的绿色说明框）不在此次改动范围内；要改需用户确认。

## 桌面修订：2026-09-24 用户确认的行为

本节覆盖下文与之冲突的交互（包括 2026-09-19 修订中的“自由讨论”条目）。实现与验证状态见 `SYSTEM_SPEC.md` 2.2、2.4、2.5。

1. **有序讨论**：所选专家在讨论开始时获取同一份前文和项目上下文，此后同轮独立并行工作，不自动读取其他专家本轮回答；界面按指定顺序展示各专家状态与回复。若设置审核专家，则待其他专家全部完成后，审核专家核查本轮各回复的事实、依据、方法和结论并给出总结。审核结果由用户决定是否加入后续上下文。
2. **标记**：用户可在聊天消息和右侧文件预览中划选文本并添加备注，可连续添加多个。输入框显示“标记 N”按钮，点击展开二级快捷窗口，整齐展示每个标记的来源、原文和备注，并支持定位、修改和移除。发送时，文字与当前全部标记共同组成下一轮输入。
3. **工具前导语**：模型在真正工具调用前产生的执行性前导文本，不作为普通助手正文显示，而归入对应工具调用/工具活动卡片；普通聊天正文只保留真正面向用户的回答和工具执行后的结论。
4. **模式简化**：取消单独的“自由讨论”。普通“工作模式”中直接通过 @专家 邀请任意专家参与，专家须清楚自己的身份；“有序讨论”仅用于结构化的多专家独立并行会诊和可选末尾审核。

5. **新建时的详情窗口**（2026-09-25 追加）：每次新建项目或独立对话，都弹出详情窗口，选择工作文件夹（可用系统选择框选已有文件夹）和 Python 环境（默认选中内置环境，也可选系统 Python）。
   项目内新建的对话继承项目设置，不弹窗；临时提问不弹窗。独立对话在点击确定之后才进入欢迎页草稿，欢迎页构图不变。详见 `design/PYTHON_ENVIRONMENTS.md`。

上下文可见性：工具调用不加入其他专家（及主专家）的上下文；其他参与者只获取回答的输出，以及该回答调用工具时涉及的文件。此修订替代 2026-09-19 的“自由讨论”与原型中的“互相质询”；旧记录不改写。

## 桌面修订：2026-09-19 用户确认的待实现行为

本节覆盖下文与之冲突的原型交互；它是实施要求，不是已完成声明。

### 补充：秘书草稿工具（用户再次确认，待实现）

“填入主专家草稿”不是每条秘书回复下固定出现的按钮。为秘书注册一个窄的应用工具（可沿用原型 writeandsend 名称，但它不发送消息）：秘书按用户意图调用，产生绑定 source secretary session、target Main chat、tool call 和 proposal ID 的可编辑提案。客户端展示编辑框，用户可修改、取消或确认发送。工具调用本身不调用 Main、不覆盖已有 Main 草稿、不授予其他工具权限；重放同一调用不得重复创建提案。当前选中的聊天不是目标身份来源，切换聊天不能让提案投错任务。

此修订取代旧的“每条回复都提供填入草稿按钮”实现方向。实现工具、持久提案和编辑框后再替换旧入口；不以删掉按钮或仅改提示词宣称已完成。

- Main、任务秘书、全局助手共享输入交互约定，但历史、草稿、运行状态分别归属自己的会话。角色提示词描述职责，不授予权限，也不代替执行策略。秘书与全局助手提供文件上传及“询问／完全接管”，不提供自动化。可授权访问全局项目，不默认注入全部项目或其他私聊。
- 选中聊天正文后出现“引用至主对话／引用至任务秘书／引用至全局助手／复制”。引用进入目标草稿，可添加批注；附件式计数按钮展开引用列表，支持查看、编辑批注、删除。引用保存来源会话、消息身份、选中文字快照；不是自动抓取最近 20 条对话。引用不自动发送，不自动产生正式科研决定。
- 文件与引用只更新目标输入区，不重挂或滚动聊天正文。跨窗口传递通过宿主保存目标草稿，窗口通知只用于刷新。异步发送成功只清除该次提交的草稿内容，不清除用户后来输入的内容。
- 运行时发送按钮变为中断；仍可编辑下一条并显式加入队列。停止当前执行与删除待发送项是不同动作。队列项固定其文本、材料、引用、目标、模型、推理强度和策略；重启后不得悄悄执行遗留队列。
- 工具调用按本次回复归组，调用与结果按 callId 配对，可展开真实参数、结果和错误；默认紧凑，回复完成收起，用户正在查看的详情不强制关闭。工具过程不再逐条追加为会话底部的系统消息，不向其他专家透传工具原文或私有思考。
- 用户上滚阅读时停止跟随新输出；附件、模式、工具和状态更新均保持阅读锚点。明确返回最新后才恢复跟随。现有最近 60 条、双向每批 30 条加载原则保留。
- 上下文圆环显示实际当前会话指标；未知显示简短“暂无数据”，不填演示数值或演示说明。推理强度来自实际模型能力；支持思考不等于支持强度调节，不以模型名字猜协议或伪造选项。
- **有序讨论的新定义：并行独立执行、固定顺序展示。** 各专家读取同一份冻结的公共输入和自己的任务、历史；按固定专家卡片展示进度与展开正文，不等待前一专家才执行。此要求替代此前“有序=串行接收前人答复”的开发计划；旧记录不重写成新语义。
- （已由 2026-09-24 修订取代：自由讨论取消，@ 邀请改在工作模式中进行。）自由讨论支持 `@` 专家候选菜单，以稳定 expertId 指派，不以可修改的显示名作为执行身份。连续多个 @ 后的共同任务可同时派发；明确分句分别派发；自然语言混合分工若不能唯一解析，先显示可编辑分工预览，不默默广播给所有专家。未点名者不自动启动。

以上修订不改变已批准的 Logo、配色和页面布局，不新增泛化权限平台或另一套 Agent loop。

## 1. 点击行为

| 入口 | 左键结果 | 右键结果 | 关闭与返回 |
|---|---|---|---|
| 顶部 文件／编辑／视图／帮助 | 按钮下方快捷菜单 | 系统默认即可 | 点击空白、Esc；键盘上下选择 |
| 项目展开箭头 | 展开／收起本项目聊天 | 项目菜单 | 展开状态独立保存 |
| 项目名称 | 打开该项目工作站 | 项目菜单 | 不改变置顶对象 |
| 项目右侧 … | 项目菜单 | 同一个项目菜单 | 操作目标是这个项目 |
| 对话名称 | 进入该对话 | 对话菜单 | 草稿与位置跟随对话 |
| 对话右侧 … | 对话菜单 | 同一个对话菜单 | 菜单项与行右键完全相同 |
| 项目置顶摘要 | 主工作区右上角锚定浮层 | 可沿用左键 | Esc、关闭键、外部点击 |
| 浏览器 | 打开／收起浏览器侧栏 | 可按需补操作菜单 | 侧栏关闭键；原对话保留 |
| 会议秘书 | 打开／收起秘书侧栏 | 可按需补操作菜单 | 草稿和未发送批注保留 |
| 模型／推理强度／运行方式 | 输入框附近的菜单 | 无特殊要求 | 选中后收起 |
| 上下文圆环 | 点击可查看；悬停是主要入口 | 无特殊要求 | 指针移走或失焦收起 |
| 计划卡片 | 非模态编辑面板 | 编辑、附件、完成、删除 | 保存／取消／Esc |
| 日志卡片任意非子按钮处 | 本项目节点详情页 | 编辑、附件、删除 | 返回工作站 |
| 导图预览左上角 | 独立导图编辑窗口 | 导图入口菜单可选 | 保存与关闭；主窗口仍可用 |
| 全局助手 | 独立浮窗 | 浮球功能菜单可后续增加 | 浮球与面板互切，主窗口不锁定 |

菜单用于选择操作；表单用于编辑对象；侧栏用于阅读当前工作相关内容；独立窗口用于并排持续工作。这是行为分类，不是要求工程新增四套框架。

## 2. 右上角项目摘要

借鉴用户给出的 Codex 截图位置。宽度约 345px，圆角、柔和灰绿底、轻阴影；没有遮罩。内容显示项目名称、变更数量、文件修改列表、最近项目节点、秘书总结和来源。文件项可以打开预览；“查看全部修改”进入细粒度修改记录页。

摘要与浏览器是两个独立开关。浏览器开启不移除顶部摘要按钮。摘要可以叠在侧栏上方，主体仍可点击；关闭摘要不关闭浏览器。

“置顶摘要”指一个项目概览入口；侧栏“置顶”指用户手动保存的项目／对话快捷引用，两者不共享自动选中逻辑。

## 3. 侧栏

上部一级导航固定；中间置顶与项目树单独滚动；“浏览全部”和用户栏固定在底部。项目折叠只改变子项可见性。省略号和右键读取同一菜单定义、同一个对象 ID。

置顶、取消置顶、重命名、归档和未读状态与“当前正在查看”分别保存。样例数据中预置一条聊天和一个项目；切换项目不会替换置顶列表。

删除对话可以撤销；项目入口移除保留实际文件，界面使用相应名称。正式产品按已有 DSH 项目和会话服务完成对象操作。

## 4. 上下文占用与缓存

圆环只表示当前目标模型会话的上下文占用。浮层中显示：模型、已用／上限、构成，以及最近请求输入／缓存读取／输出。缓存命中不从上下文占用中扣除。实现须区分供应商原始 input 口径和 DSH 规范化的 uncachedInput/cacheRead/cacheWrite 字段，不能把已包含缓存的总输入再次加上缓存，也不能把累计多次请求用量当成当前上下文。累计账户用量放在“用量分析”，本次附件和批注放在独立侧栏。

原型数值为明确标注的示例。正式版采用运行时可取得的指标；估计注明“估计”，未知显示“未知”，不得使用预设百分比假装实时数据。

## 5. 对话记录

用户消息右对齐，保留浅灰绿色底；专家消息左对齐。消息显示日期分隔、作者、时间。复制、从此分支、更多菜单位于消息下方，悬停或键盘焦点时更清晰。

分支从被选消息的历史前缀开始，记录来源聊天与消息。分支后的新消息不自动回写原聊天。这个原型验证交互与独立状态；生产环境继承多少运行时内容、如何处理工具历史，复用 DSH 当前支持的会话能力。

消息位置有稳定的 project/thread/message 身份。日志节点保存可选关联，点击“定位到消息”先打开目标对话，再加载包含该消息的分页、滚动居中并短暂高亮；消息被删除时展示原引用和失效状态，不跳到另一个近似位置。HTML 的示例节点已接通精确跳转。

## 6. 键盘与可访问性

原型快捷键：Ctrl K 搜索与命令；Ctrl Shift K 浏览全部；Ctrl F 对话内查找；Ctrl N 新建项目聊天；Ctrl Alt N 独立快速聊天；Alt S 摘要；F2 重命名焦点所在项目／对话；Esc 关闭当前菜单／浮层。菜单支持上下、Home、End、Enter；中文输入法组合期间不触发发送或节点新建。

输入框 Enter 发送，Shift Enter 换行；导图 Enter 同级新建、Shift Enter 框内换行、Tab 添加子分支。菜单右侧显示快捷键；桌面宿主可按平台注册并处理与系统的冲突。

滚动条默认隐藏，滚动、触控板、键盘仍工作；“视图 → 显示滚动条”提供显式选择。显示缩放、字距和较窄窗口不能遮挡输入框、发送和关闭按钮。
