# ScienceScope 前端功能总说明

版本 v0.3，2026-09-17。本版以用户最新版 PPT、逐条交互反馈和已认可的 HTML 视觉风格为依据。页面样式与交互用于本地 Codex 建设基于完整 DeepSeek Harness 的新应用。

## 产品目标

学者与多个 AI 围绕真实材料共同研究，能够查看、提问、讨论、发现盲点、检查实际改动并决定下一步。以完整 DSH 的现成应用和工具为起点逐步改进。专家默认共用项目阅读和管理能力，主要通过 system prompt 形成工作侧重；每位专家一个可复用子代理。会议秘书承担项目材料、版本说明、摘要和导图的日常整理。

## 应用整体

顶部：Logo、文件／编辑／视图／帮助菜单。左侧：新对话、数据库、工作站、手动置顶、项目聊天树；底部固定浏览全部、用户、全局助手和设置。主体：工作聊天或所选页面。右侧：按需的浏览器／秘书／文件与批注。项目摘要在主工作区右上角浮出。

49 个页面状态继续保持上版编号 P01—P48；P49 新增完整项目修改记录。界面采用原来的灰白背景、浅绿选中、黑色主按钮、细分隔线、圆角和低密度辅助文字。用户给定 Logo 原样保留。

## 导航与会话

项目名称进入对应工作站；箭头展开或收起本项目聊天；聊天名称打开该对话。项目与对话右侧省略号及行右键显示同一菜单。置顶只由用户选择；切项目与切聊天不更改置顶。

浏览全部固定在左侧底部，打开所有对话表，支持名称与已加载消息搜索、全部／置顶／未读／已归档筛选。Ctrl K 搜索项目、对话和应用操作；Ctrl F 在当前对话中查找。

项目内不同聊天有独立草稿和工作记录。页面或项目切换后可继续输入；新建分支从选中消息的前缀开始，记录来源位置。正式版用 DSH 会话／分叉能力完成运行时语义。

## 主工作区

用户消息靠右，专家消息靠左；日期分隔、作者、时间、复制、从此分支和消息菜单可见。工具过程默认简要折叠；可在工作区菜单切换简洁执行记录。产物可在右侧预览或从系统默认程序打开。

输入框容纳正文、文件、图片、材料引用、历史消息和多条临时批注。附件可选择、粘贴或拖入。运行方式、模型和推理强度使用菜单。模型上下文圆环的悬停显示当前占用和最近请求缓存信息；来源选择与批注有单独入口。

正式发送确认接收后清除本次标记，保留发送时的版本与说明快照。发送失败保留草稿和标记；发送期间新增/修改的标记不会被旧回执删除。异步提交归属发起时的聊天，页面切换不会改投另一项目。

## 会议与秘书

工作（可用 @专家 邀请专家回答）、有序讨论（并行独立会诊与可选审核）保持用户预设的协作方式（2026-09-24 起取消单独的自由讨论）。参与者和角色模型可配置；运行状态按真实事件呈现。秘书可私下解释材料、整理当前意见、帮助用户准备下一步提示词。

writeandsend 生成可编辑草稿卡，显示目标项目/聊天与随附标记。用户编辑后点击发送才进入主工作区。秘书问答不消耗未提交批注，也不自动记成正式修订。正式工作理论调整、文本改动和版本关系由对应记录保存。

## 工作站

全局计划在顶部：简洁事项，标题、可选项目/备注、附件和完成状态。支持创建、编辑、删除、撤销及文件添加。它服务全局总览，不强制细分任务管理。

中部是当前项目的关键日志：完成的工作和大节点。日志按项目切换，整张卡可打开详情；支持新建、编辑、补充文件、删除/撤销。“定位到消息”打开相关聊天并滚动到实际消息，详见交互说明。

下部保留用户 PPT 三个区域：文献版本、研究框架与进展、项目文件夹。

文献版本可拖入文件。正式版上传后触发秘书比较前一版本及相关研究上下文，创建随版本保存的说明 MD。版本可打开、查看说明、比较、引用和在资源管理器定位。原型接收真实文件，生成明确标注的说明模板；AI 总结在本地应用接入。

研究导图保持纵向主干与花括号分支。工作站预览支持缩放、平移、选中、展开和收起；左上角按钮打开独立编辑窗口。编辑器支持 Markdown 和图片的选择/拖入/粘贴/右键插入、缩略图上限、节点顺序、撤销重做、导出与保存同步。Enter 创建同级元素，Shift Enter 在当前框换行，Tab 创建子分支。

项目文件区表现为简易资源管理器；目录展开，文件默认程序打开，提供资源管理器定位。原型仅展示目录和文件打开入口，真实系统调用由桌面应用接入。

## 修改与版本

项目日志记录重要节点，细粒度修改记录另外展示创建、修改、删除、重命名及实际来源。摘要显示近期变化，完整记录页可继续查看。文稿理论、段落和字词级修订与对应版本关联。批注绑定被选版本；发送并不意味着实际文件已完成修改。

## 数据库和外部资源

保留当前项目材料、我的资料和外部资源页面。材料保存、解析与索引状态分别展示。外部资源区区分书签、网页登录和工具连接的状态；默认应用阅读与工作区预览互补。普通 UI 不展示重复口号，具体能力及未接通原因放在状态或帮助里。

## 浏览器与多窗口

浏览器侧栏有关闭、地址、前进后退、刷新、引用和独立窗口。打开浏览器不影响摘要按钮。辅助表单和独立窗口不阻塞主聊天。

全局助手在主窗口外，球与面板互切。项目、数据库、工作站等动作可激活主应用的相应位置。正式桌面版接入悬浮球、置顶、屏幕位置、截图和跨窗口行为；HTML 演示的是独立浏览窗口与联动。

## 设置

一般设置、人格与记忆、模型/API、用量、专家、秘书、全局助手、插件、环境、浏览器、快捷键等保留对应页面。功能说明侧重用户能做什么及生效范围；同一运行显示实际采用的模型和参数。角色侧重主要通过 prompt 表达。

## 文件位置

应用自身的配置、数据、日志、缓存、技能、下载/临时文件和运行目录尽量位于安装目录内；可用统一 data/ 下的具体子目录组织，由开发结合 DSH 调整。用户主动选择的外部研究文件夹可作为工作空间。后续接入 Codex / Claude Skills 时，明确选择外部来源；ScienceScope 自己创建的 Skills 保存在自己的目录。更新应用程序时保留用户数据和配置。

## 开发使用顺序

先打开 ScienceScope.html 逐项体验本轮反馈；读 02_INTERACTION_CONTRACTS.md 与本页功能规格；在完整 DSH 中寻找对应 UI、会话、工具和窗口能力，按真实使用路径接线。逐页规格为行为参照，不强迫新增同名后端包、角色授权矩阵或通用插件平台。

本轮 QA 对实际页面、交互、附件、批注、状态和独立窗口做验证。真实 Provider、DSH 执行、模型上下文计数、操作系统资源管理器、网页内核和安装包留给本地环境验收。
