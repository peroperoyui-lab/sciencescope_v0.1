# P34 安全与工作偏好

版本 v0.3；路由 `#behavior`。

## 目的与入口

用简单工作预设说明何时询问、如何使用文件和网络。

入口：设置安全配置。

依据：PPT 安全配置 + 最新轻约束要求。本轮菜单/窗口定义见 `../02_INTERACTION_CONTRACTS.md`，与早期原型描述不同处以本轮为准。

## 页面组成

- 询问后进行/完全接管/自动化预设。
- 公共工作提示与文件操作偏好。
- 每位专家一个子代理说明。

## 用户操作与结果

- 选择预设并查看自然语言行为说明。
- 调整删除前确认、网络使用、外部编辑习惯。
- 修改共同提示后供下次工作使用。

## 状态

- 默认预设
- 自定义说明

## 验收

- 专家不用逐人配置复杂权限矩阵。
- 用户可直接理解每个预设。

## 开发接入

首先检查完整 DSH 已有的对应组件和服务。原型的入口和结果作为功能依据，数据保存、模型调用及操作系统能力接入真实应用。未配置/不可用时用具体状态反馈，保持其他功能可用。
