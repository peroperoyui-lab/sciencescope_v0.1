# P26 创建项目 · 文件夹

版本 v0.3；路由 `#project-new`。

## 目的与入口

快速为研究建立标题与工作目录。

入口：项目树加号；全局助手从文件夹创建。

依据：PPT 新项目入口 + 安装目录要求。本轮菜单/窗口定义见 `../02_INTERACTION_CONTRACTS.md`，与早期原型描述不同处以本轮为准。

## 页面组成

- 项目标题、研究目标简述。
- 默认安装目录内路径/用户选定文件夹。
- 已有文件概览与创建。

## 用户操作与结果

- 填写标题即可创建；可选择已有文件夹。
- 创建后进入项目首页并显示材料位置。
- 秘书根据当前目标建立首份项目说明和导图草稿。

## 状态

- 空项目
- 现有文件夹
- 路径不可写

## 验收

- 用户能看见实际项目路径。
- 默认新项目位于安装目录内的数据区。

## 开发接入

首先检查完整 DSH 已有的对应组件和服务。原型的入口和结果作为功能依据，数据保存、模型调用及操作系统能力接入真实应用。未配置/不可用时用具体状态反馈，保持其他功能可用。
