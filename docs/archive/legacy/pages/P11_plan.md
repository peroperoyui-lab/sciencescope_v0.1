# P11 全局计划

版本 v0.3；路由 `#plan`。

## 目的与入口

用很少输入记下未来工作。

入口：工作站添加计划；点击计划卡。

依据：用户计划总览修正。本轮菜单/窗口定义见 `../02_INTERACTION_CONTRACTS.md`，与早期原型描述不同处以本轮为准。

## 页面组成

- 简单计划卡列表。
- 非模态编辑器包含标题、可选项目、备注和文件。

## 用户操作与结果

- 新建、编辑、切换完成状态、删除并撤销。
- 选择文件或拖入附件区，可移除附件。
- 编辑器打开时继续使用主工作区，表单目标保持不变。

## 状态

- 新计划
- 已完成
- 无所属项目

## 验收

- 空标题有反馈。
- 切项目不丢全局计划。
- 附件属于相应计划。

## 开发接入

首先检查完整 DSH 已有的对应组件和服务。原型的入口和结果作为功能依据，数据保存、模型调用及操作系统能力接入真实应用。未配置/不可用时用具体状态反馈，保持其他功能可用。
