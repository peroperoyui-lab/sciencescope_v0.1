# P15 研究导图 · 二级编辑窗口

版本 v0.3；路由 `#map`。

## 目的与入口

通过 GUI 管理纵向研究框架、括号分支和内容块。

入口：工作站导图左上角按钮，打开二级窗口。

依据：PPT 4 页导图 + 最新要求 2。本轮菜单/窗口定义见 `../02_INTERACTION_CONTRACTS.md`，与早期原型描述不同处以本轮为准。

## 页面组成

- 顶部返回、保存、撤销重做、插入和导出。
- 中间可平移缩放画布：纵向主干，右侧花括号分支。
- 右侧选中节点属性；底部缩放。

## 用户操作与结果

- 从工作站左上角打开独立编辑窗口。
- Enter 同级、Shift Enter 换行、Tab 子分支。
- Markdown/图片选择、粘贴、拖入、右键插入。
- 移动/删除节点，撤销重做，设置缩略图大小。
- 保存预览同步到对应项目，支持 JSON/Markdown 导出。

## 状态

- 空导图
- 节点选中
- 编辑中
- 存在未保存改动
- 其他 Agent 更新

## 验收

- 预览与编辑窗口共享同一个项目导图。
- 中文输入法确认文字的 Enter 不误建节点。

## 开发接入

首先检查完整 DSH 已有的对应组件和服务。原型的入口和结果作为功能依据，数据保存、模型调用及操作系统能力接入真实应用。未配置/不可用时用具体状态反馈，保持其他功能可用。
