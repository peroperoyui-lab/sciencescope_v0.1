# P33 数据库设置

版本 v0.3；路由 `#library-settings`。

## 目的与入口

管理材料位置和可用读取能力。

入口：设置数据库设置。

依据：PPT 6 页。本轮菜单/窗口定义见 `../02_INTERACTION_CONTRACTS.md`，与早期原型描述不同处以本轮为准。

## 页面组成

- 资料库目录、项目默认目录。
- 文件类型读取、索引状态。
- 导入与整理偏好。

## 用户操作与结果

- 打开目录、调整默认位置。
- 查看解析/索引工具，重建选定索引。
- 设置导入后是否加入当前项目。

## 状态

- 目录就绪
- 重建中
- 工具需要配置

## 验收

- 原件位置清楚。
- 用户能看见哪些内容已可被 Agent 读取。

## 开发接入

首先检查完整 DSH 已有的对应组件和服务。原型的入口和结果作为功能依据，数据保存、模型调用及操作系统能力接入真实应用。未配置/不可用时用具体状态反馈，保持其他功能可用。
