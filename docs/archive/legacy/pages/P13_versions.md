# P13 文献版本管理 · 导入

版本 v0.3；路由 `#versions`。

## 目的与入口

把稿件或文献的不同版本放在可管理目录，自动得到版本说明。

入口：工作站左下区展开；拖入文件。

依据：PPT 4 页 + 最新要求 1。本轮菜单/窗口定义见 `../02_INTERACTION_CONTRACTS.md`，与早期原型描述不同处以本轮为准。

## 页面组成

- 文献/稿件组和各版本。
- 拖入区、添加文件、资源管理器打开。
- 秘书处理状态。
- 原件、跟随说明 MD、比较和上下文入口。

## 用户操作与结果

- 拖入或选择文件，选择已有文献组或新文献。
- 文件保存完成后自动排入秘书总结工作。
- 秘书比较指定前一版本及当前研究上下文，创建跟随说明 MD。
- 同批文件顺序可调整；失败可重试，原件随时可打开。

## 状态

- 首版无旧版本
- 多文件导入
- 等待秘书
- 正在比较
- 完成
- 总结失败

## 验收

- 每版都有可定位的说明 MD 或明确的待处理状态。
- 不同文献组的比较对象可见且可更正。

## 开发接入

首先检查完整 DSH 已有的对应组件和服务。原型的入口和结果作为功能依据，数据保存、模型调用及操作系统能力接入真实应用。未配置/不可用时用具体状态反馈，保持其他功能可用。
