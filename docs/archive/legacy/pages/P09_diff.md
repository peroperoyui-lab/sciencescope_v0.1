# P09 版本比较 · 字词变化

版本 v0.3；路由 `#diff`。

## 目的与入口

看清文章、理论与代码的实际修改内容。

入口：修改记录的比较；版本列表选择两个版本。

依据：用户修改/版本要求。本轮菜单/窗口定义见 `../02_INTERACTION_CONTRACTS.md`，与早期原型描述不同处以本轮为准。

## 页面组成

- 左右版本选择、并排/统一视图。
- 增加、删除、替换和位置变化。
- 关联请求、批注、秘书说明。

## 用户操作与结果

- 选择旧版本和新版本比较。
- 按变化跳转；复制原文或创建批注。
- 打开两个原件；恢复选定内容后产生新的版本。
- 查看导致此次修改的用户请求和说明。

## 状态

- 文本可比较
- 格式仅原件可打开
- 无变化
- 比较处理中

## 验收

- 相同内容可复用，但不同修改动作可追溯。
- 恢复版本后仍可查看恢复前记录。

## 开发接入

首先检查完整 DSH 已有的对应组件和服务。原型的入口和结果作为功能依据，数据保存、模型调用及操作系统能力接入真实应用。未配置/不可用时用具体状态反馈，保持其他功能可用。
