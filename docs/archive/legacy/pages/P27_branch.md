# P27 分支工作 · 新探索

版本 v0.3；路由 `#branch`。

## 目的与入口

从当前问题探索另一种方法，同时保持来源可查。

入口：输入框上方创建新的分支工作。

依据：PPT 3 页分支工作。本轮菜单/窗口定义见 `../02_INTERACTION_CONTRACTS.md`，与早期原型描述不同处以本轮为准。

## 页面组成

- 分支名称、源聊天/消息。
- 继承材料和摘要。
- 输出位置与创建。

## 用户操作与结果

- 选择继承的上下文与材料版本。
- 进入独立聊天，保留源分支关系。
- 比较结果后用户决定合并哪些成果。

## 状态

- 未命名
- 材料已更新
- 创建成功

## 验收

- 从选中历史前缀建立独立消息状态。
- 分支后新增内容不污染原聊天。
- 正式运行时历史和文件输出由 DSH 对应能力接入。

## 开发接入

首先检查完整 DSH 已有的对应组件和服务。原型的入口和结果作为功能依据，数据保存、模型调用及操作系统能力接入真实应用。未配置/不可用时用具体状态反馈，保持其他功能可用。
