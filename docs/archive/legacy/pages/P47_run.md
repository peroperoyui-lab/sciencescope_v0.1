# P47 运行详情 · 工具与子代理

版本 v0.3；路由 `#run`。

## 目的与入口

看清哪个专家在做什么、实际结果在哪里。

入口：聊天工具卡、专家活动、用量明细。

依据：PPT 3 页工具执行 + 每专家一个子代理。本轮菜单/窗口定义见 `../02_INTERACTION_CONTRACTS.md`，与早期原型描述不同处以本轮为准。

## 页面组成

- 任务、执行者和时间。
- 工具输入输出、成果。
- 唯一子代理槽与返回结果。

## 用户操作与结果

- 展开具体工具活动。
- 停止本次执行，保留已产生结果。
- 打开产物或将失败发给秘书。

## 状态

- 运行中
- 已完成
- 正在停止
- 失败
- 子代理空闲

## 验收

- 模型提到某工具与真实调用分开。
- 每位专家的子代理归属明确。

## 开发接入

首先检查完整 DSH 已有的对应组件和服务。原型的入口和结果作为功能依据，数据保存、模型调用及操作系统能力接入真实应用。未配置/不可用时用具体状态反馈，保持其他功能可用。
