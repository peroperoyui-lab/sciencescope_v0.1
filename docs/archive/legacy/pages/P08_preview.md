# P08 文件预览 · 临时多批注

版本 v0.3；路由 `#preview`。

## 目的与入口

在右侧预览中对多个片段提出具体问题或修订意见。

入口：概览、版本列表、成果卡中的预览。

依据：用户逐版本批注明确要求。本轮菜单/窗口定义见 `../02_INTERACTION_CONTRACTS.md`，与早期原型描述不同处以本轮为准。

## 页面组成

- 文件名与版本选择。
- 正文预览及选中工具条。
- 临时批注清单与说明输入。
- 主输入框和秘书入口。

## 用户操作与结果

- 选中文字添加一次性标记，连续添加多处。
- 每个标记附说明；点击列表定位原文。
- 发送主工作区时连同正文提交，接收后清除并与版本关联。
- 先问秘书保留标记，临时批注不进入正式研究记录。

## 状态

- 无选区
- 有多个批注
- 旧版本已更新
- 提交失败

## 验收

- 批注绑定文件版本与原文，不随新版本漂移。
- 第一个提交完成后仍保留后来新建或编辑的标记。

## 开发接入

首先检查完整 DSH 已有的对应组件和服务。原型的入口和结果作为功能依据，数据保存、模型调用及操作系统能力接入真实应用。未配置/不可用时用具体状态反馈，保持其他功能可用。
