# 本轮十条反馈落实表

| 用户反馈 | 原型当前结果 | 本地开发验收 |
|---|---|---|
| ① 菜单／浮层混用 | 顶部四菜单、项目／对话双入口菜单、输入框选项菜单；摘要为右上角浮层；上下文圆环显示占用及缓存 | 原生菜单键位、真实统计、窄屏定位 |
| ② 浏览全部置底 | 固定于侧栏底部；完整对话表、标题／消息搜索、置顶／未读／归档筛选 | 对接真实会话列表和分页 |
| ③ 文案过多 | 移除首页与常规页面的重复口号；保留字段、状态、错误和必要帮助 | 新页面沿用简洁文案 |
| ④ 计划日志附件与卡片 | 计划／日志有附件选择和拖入；日志整卡可点击；节点可定位到示例消息 | 默认程序打开附件；稳定消息锚点与历史分页 |
| ⑤ 置顶与项目树 | 用户手动置顶／取消；项目可展开收起；切换不改置顶 | 保存偏好与真实对象变更 |
| ⑥ 消息布局与快捷动作 | 用户消息右对齐；每条复制、分支、更多；日期与时间 | 真实消息身份、分支历史与成果继承 |
| ⑦ 浏览器和二级窗口 | 摘要按钮常驻；浏览器可关闭／分离；表单非模态 | 浏览器内核、下载、cookie、原生窗口尺寸 |
| ⑧ 滚动条 | 默认隐藏；视图菜单可显示；保留滚动与键盘操作 | Windows 缩放和触控板实测 |
| ⑨ 全局助手 | 真独立浏览窗口；球形收起／恢复；操作定位主应用 | OS 悬浮球、置顶、移动／贴边与系统快捷键 |
| ⑩ 创建删除 | 计划和项目日志创建、编辑、删除、撤销均可操作 | 对接持久化文件和秘书整理结果 |

## 本轮主动补充

搜索与命令（Ctrl K）、当前对话查找（Ctrl F）、已归档对话查找、消息链接与节点定位、输入框文件粘贴／拖入、手动已读／未读、执行记录密度切换、主聊天草稿独立保存。它们在现有页面内改善操作，不改变用户 PPT 的整体信息架构。

## 原型与正式能力

原型的本次提交回执、文件附件、节点、置顶、消息和计划修改在内存中真实发生。模型调用、秘书自动总结、上下文数值、外部网页正文和部分设置属于已标明的示例。不同层次在开发时分别验收；沿用完整 DSH 的成熟实现。
