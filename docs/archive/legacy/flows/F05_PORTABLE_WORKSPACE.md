# F05 · 安装目录内的整洁工作环境

## 用户可见目标

ScienceScope 自己安装、生成和缓存的文件尽量留在安装目录。用户在环境配置页可以看到实际位置，并打开对应目录。

推荐呈现为：

```text
ScienceScope/
  应用与运行所需文件
  data/
    dsh/         模型配置、会话和运行资料
    projects/    默认新建项目
    library/     自身资料库
    skills/      自身技能
    plugins/     自身扩展
    browser/     浏览器会话
    downloads/   下载
    cache/       缓存
    temp/        临时文件
    logs/        软件诊断
```

这是功能位置说明，实际名称由所选完整 DSH 与桌面宿主整合；环境页显示最终真实路径。

## 项目内可见内容

项目文件夹中能找到原始材料、文献各版本、对应说明 Markdown、研究导图及图片、项目总结、代码和成果。用户通过系统资源管理器也能理解内容位置。

## 已有文件与外部技能

用户可明确选择已有项目文件夹。未来引用 Codex、Claude 的 skills 时，界面显示外部来源和自身使用方式；ScienceScope 自己的技能继续放入自己的目录。外部程序和操作系统所产生的自身数据按实际行为说明。

## 安装与退出体验

启动时检查当前目录可写。需要换位置时由用户选择。更新应用时保留 data 内容；移动便携目录后能继续找到自身配置与项目。正常退出收口任务与相关进程，托盘驻留由用户选择，当前状态可见。

## 验收

在干净 Windows 用户环境安装、运行、上传版本、编辑导图、打开默认程序、使用模型与插件、正常退出。记录 ScienceScope 自身文件的实际位置，核对目录移动、更新保留数据和完整退出。
