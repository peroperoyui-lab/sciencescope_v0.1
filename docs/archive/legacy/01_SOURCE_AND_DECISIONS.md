# 设计依据与本轮决定

本轮在已交付的 ScienceScope 48 页 HTML 原型上迭代，没有重新设计视觉主题。优先级：用户最新十条交互反馈 → 新版 PPT 的页面结构 → 既有已认可风格 → 本轮成熟产品研究得到的细节补充。

参考目录中包含用户最新 PPT、给出的 Codex 截图与原 Logo。PPT 规定主要布局；Codex 截图用于右上项目摘要浮层的位置、锚定、质感和操作层次，不意味着复制其深色主题。

## 已确定

- 顶部菜单、项目／对话省略号和右键均使用快捷菜单。
- 摘要为右上浮层；引用／批注仍保留在独立右侧栏；上下文圆环单独反映模型 Token 与缓存。
- 手动置顶对象独立于当前正在看的对象；项目树可折叠。
- 全局计划简单；项目日志只记录重要节点；修改记录保留细节。
- 用户消息右对齐，有时间、复制与分支；日志可以跳到具体消息位置。
- 全局助手与导图为独立窗口，主应用不锁定；浏览器有关闭、分离和正常导航控件。
- 专家共用能力，以提示词形成角色侧重；会议秘书承担项目整理；用户决定下一步。
- 自有文件尽量放在安装目录；外部研究空间和未来外部 Skills 来源由用户显式选择。

## 本轮补充

Ctrl K 搜索与命令、Ctrl F 当前对话查找、浏览全部中的消息搜索和归档筛选、轻量删除撤销、文件附件粘贴／拖入、执行记录密度、稳定消息位置及当前会话草稿保存。

这些补充集中在现有页面，不再要求额外的权限矩阵、插件平台或总调度框架。正式实现从完整 DSH 现有能力出发。

## 保留的解释

导图“减号表示展开”沿用上轮与通常树形交互一致的解释：加号新增/展开，减号收起。预览可缩放平移但不能编辑正文；二级窗口负责编辑。

## 状态说明

HTML 已接通本轮可测试的浏览器交互。原型数据主要是内存示例；真实模型、秘书比较、上下文遥测、OS 文件打开、浏览器引擎和安装包并未在本轮接通。这些能力在对应页面文档中分别声明。
