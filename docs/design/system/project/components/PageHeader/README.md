44px 页头：页面标题、范围或成员、一行页内标签和至多三个页面操作。

## 结构

`ss-header` 里依次放 `ss-header__title`、可选的 `ss-select--ghost`（范围）或头像组、`ss-header__sep`、`ss-tabs`，最后是 `ss-header__actions`。

- 子页面在最左放返回按钮（arrow-left 图标，快捷键 Alt ←）。
- 页面说明放进 `ss-info`，不写在页面上。

## 规则

- 不用面包屑和大号页面标题；页头就是唯一的标题区。
- 操作最多三个，图标按钮在前，带文字的主操作在最后；其余进 ⋯。
- 右侧面板的头部同样 44px，两者底边对齐。
