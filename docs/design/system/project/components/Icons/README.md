全站只用一套 Lucide 线性图标：16px，线宽 1.75，一个含义只对应一个图标。

## 用法

- 写 `<i data-i="图标名"></i>`，组件脚本会换成内联 SVG（类名 `ss-i`）；`ss-i--sm` 是 14px。
- 颜色跟随文字：默认 `ink-2`，次要位置 `muted`，状态图标用 `warn`、`danger`、`accent`。
- 卡片里列出了每个图标的中文含义；新增含义时先加进这张表，再使用。

## 规则

- 同一个含义在所有页面用同一个图标（定位到消息永远是 locate，筛选永远是 funnel）。
- 不用 emoji，不混用其他图标库，不画自制图标。
- 只有图标的按钮必须带提示。
