输入框：一个圆角框里放附件、输入区和底栏；执行方式、上下文用量、模型和思考强度都在底栏，发送和停止是同一个按钮。

## 结构

`ss-composer-wrap` 里放 `ss-composer`（最宽 `chat`，圆角 `r-xl`，`raised` 底），从上到下是：

- `ss-composer__files`：附件和引用的资料，每个是一个 `ss-file-chip`（图标、名称、移除按钮）。没有附件时这一行不出现。
- `ss-composer__input`：会自动长高的 `textarea`，超过 200px 后滚动。占位符写这里能做什么，如「回复主专家，输入 @ 叫其他专家」。
- `ss-composer__bar` 底栏，从左到右：
  - 「添加」图标按钮，菜单里有添加文件、引用资料库、叫其他专家；
  - 执行方式按钮，见 ModeMenu；
  - `ss-composer__spacer`；
  - 上下文圆环 `<i data-ring="34" data-warn="80">`，提示里写已用比例和数量；
  - 模型和思考强度按钮，见 ModelPicker；
  - SendButton。

## 规则

- 输入框上方不放说明文字和提示条。说明写进占位符或 ⓘ。
- 上下文圆环到压缩门槛（`data-warn` 写设置里的值，默认 80）变成 `warn`，到 95% 变成 `danger`。到了门槛，下一次发送前自动整理较早的对话，时间线里留一行记录。
- 发送用 Enter 还是 Ctrl Enter 按设置来，另一个组合用来换行。
- 可以把文件直接拖进输入框添加附件。
- 秘书面板里用同一个组件的紧凑版：只留添加、模型和发送，没有执行方式和圆环。
