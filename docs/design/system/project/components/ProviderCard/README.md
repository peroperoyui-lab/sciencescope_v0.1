服务商卡片：头部写名称、地址、连接状态和一个下一步按钮；下面自动列出这个服务商的模型和上限。

## 结构

`ss-provider` 由头部和表格两部分组成。

- `ss-provider__head`，从左到右：
  - `ss-preset__mark--sm`：服务商缩写，或者 plug 图标；
  - `ss-provider__main`：`ss-provider__name`，以及写地址和密钥状态的 `ss-provider__meta`；
  - `ss-provider__status`：`ss-dot` 加结果；
  - 一个按钮；
  - ⋯ 菜单：重新获取模型列表、更新密钥、编辑地址、移除服务商。
- `ss-provider__body`：模型表，列出模型、上下文、最长输出、思考强度和上限来源。
  - 上限来源写「目录」「匹配」或「默认值」，含义放在 ⓘ 里。

快速添加用 `ss-presets`：

- 每个预设是一个 `ss-preset`，里面有标志、名称、一句说明和「添加」按钮；已经加过的显示「已添加」。
- 最后放一个「其他兼容服务」入口，填地址和密钥。

## 状态的写法

| 状态 | 圆点和文字 | 按钮 |
|---|---|---|
| 正常 | `ok` 圆点，「连接正常 · 820 ms」 | 「测试连接」 |
| 测试中 | 转圈，「正在测试」 | 禁用 |
| 出错 | `danger` 圆点，原因和下一步，如「密钥无效，请重新填写」 | 直接给解决办法，如「更新密钥」 |

## 规则

- 密钥保存后不再显示，只写「密钥已保存」。要更新，就在对话框里重新填。
- 添加服务商只需两步：选预设，填密钥。OpenCode Go 订阅的地址和模型一步配好。
- 模型上限自动获取，不提供手动填写的入口。
- 「移除服务商」放在 ⋯ 菜单最后，确认后才执行。如果默认模型属于这个服务商，提示用户改选。
