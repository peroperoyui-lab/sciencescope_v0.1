全站统一的悬停提示：深色小条，贴着触发元素出现，可以带快捷键。

## 用法

- 在元素上写 `data-tip="文字"`；有快捷键加 `data-kbd="Ctrl N"`。
- 默认出现在下方，放不下时翻到上方，再左右平移留出 8px 边距；需要指定时写 `data-tip-place="top"`、`"right"`、`"bottom-end"` 等。
- 悬停 0.5 秒出现；刚关掉 0.4 秒内移到相邻元素，立即出现。
- 解释性文字放进 `ss-info`（i 图标按钮），悬停或键盘聚焦时显示。

## 规则

- 只有图标的按钮必须有提示；带文字的按钮不重复提示。
- 提示写名称或一句状态，最宽 260px；长说明放进 Popover。
- 不用 `title` 属性，不把提示固定在屏幕某个角落。
- 颜色来自 `tooltip` 和 `on-tooltip`，两个主题都一样深。
