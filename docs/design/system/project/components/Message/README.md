对话里的一条消息：用户消息靠右成气泡；专家、任务秘书和全局助手的消息不加框，头部是头像、名字和模型。

## 结构

- 外层 `ss-thread`：最宽 `chat`，消息之间 20px。
- 用户消息：`ss-msg ss-msg--user` 里放 `ss-msg__bubble`（`sunken` 底，14/22，保留换行）。
- 助手消息：`ss-msg` 里依次放 `ss-msg__head`（`ss-avatar`、`ss-msg__name`、`ss-msg__role`）、可选的行动时间线 `ss-act`、`ss-msg__body`（14/22，左缩进 28px，和名字对齐）。
- `ss-msg__role` 写模型名，或者这个角色正在做什么（如「跟进到第 6 条」）。
- 引用资料：正文里写 `<span class="ss-cite" data-tip="资料全名">S1</span>`，点一下在右侧预览这篇资料。
- `ss-msg__foot`：助手消息是复制、重新回答和 ⋯，用户消息是编辑、复制；最后是时间和用时。悬停或聚焦时才出现。

## 规则

- 主专家、其他专家、任务秘书和全局助手用同一套消息组件，只换头像和名字，不给某个角色做专门的样式。
- 专家头像用名字的第一个字；秘书和助手用图标。用户自己的消息不显示头像。
- 正文里的文件路径写成链接，点一下在右侧预览。
- 正文里不堆按钮。需要用户去别处处理的事写成一个链接，如「去收件箱确认」。
