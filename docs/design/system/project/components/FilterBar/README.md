筛选栏：搜索、漏斗和排序放在一行，生效的筛选显示成可以删除的小标签。

## 结构

- `ss-toolbar` 里依次放 `ss-input` 搜索框、漏斗 `ss-icon-btn`（`data-pop` 打开筛选面板，角标写已选条件数）、排序 `ss-select--ghost`、`ss-toolbar__spacer`、数量文字、视图切换。
- 下一行 `ss-chips`：每个条件一个 `ss-chip`（名称 + `<b>` 值 + 删除按钮），最后是 `ss-linkbtn`「清除筛选」。

## 规则

- 不把筛选条件摊成一排下拉框。
- 没有生效的条件时，小标签这一行整行隐藏。
- 数量写「5 / 8 篇」，让人知道有内容被筛掉了。
