第三章　研究设计

3.1　研究方法

本章采用模糊集定性比较分析（fsQCA）识别城市经济韧性的条件组态。与传统回归关注单一变量的净效应不同，组态视角关注多个条件如何共同导致结果。

经济韧性指数采用熵权法合成，涵盖抵抗力和恢复力两个维度，各维度下设 4–6 个二级指标。

本研究的创新之处主要体现在以下三个方面：一是从组态视角解释城市经济韧性，二是构建了多维指标体系，三是结合面板数据检验稳健性。

3.2　样本与数据

研究样本为 102 个地级市，时间跨度为 2010–2020 年，数据主要来自《中国城市统计年鉴》。

第三章　研究设计

3.1　研究方法

本章采用模糊集定性比较分析（fsQCA）识别城市经济韧性的条件组态，并以面板回归检验结论的稳健性。与传统回归关注单一变量的净效应不同，组态视角关注多个条件如何共同导致结果，适合解释“多条路径通向同一结果”的现象。

经济韧性指数采用熵权法合成，涵盖抵抗力、恢复力与再组织能力三个维度，各维度下设 4–6 个二级指标，权重由各指标的信息熵确定。

3.2　样本与数据

研究样本为 98 个地级市，时间跨度为 2010–2022 年，数据主要来自《中国城市统计年鉴》和各市统计公报，缺失值用线性插值补齐。

结果表明，在样本量为 98 的条件下，组态方法的解释力总体高于基线模型，但对东部城市的区分度有限。
