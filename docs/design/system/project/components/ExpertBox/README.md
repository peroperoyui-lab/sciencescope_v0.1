专家状态框：有序讨论时，还在发言的专家不展开时间线和长回答，只占一个固定高度的框，好让几位专家同时看得见。

## 结构

`ss-expert-box` 放在专家消息头下面，代替时间线、正文和状态行：

- `ss-expert-box__head`：当前一步（转圈或图标、动词、`ss-expert-box__target`、右侧用时）。等批准时加 `ss-expert-box__head--wait`（`warn`）。
- `ss-expert-box__tail`：最后三行，贴底显示，顶部渐隐。优先显示正在写的回答，其次是当前一步之前的前导语，再次是正在进行的思考（`ss-expert-box__tail--thought`，`muted`）。
- 还没轮到的专家只有一行：clock 图标和「等前面的专家说完」。

## 规则

- 高度固定，内容再长也不撑开；说完后整框换成完整回答和收起的时间线。
- 需要批准时，批准卡片紧跟在框下面，不能藏进框里。
- 只用于有序讨论（包括审核人）；主对话、任务秘书和全局助手照常显示时间线。
