整页示例：知识库（图）。围绕一个中心节点看它的关系，默认一层；不画整库。

## 区域

- 页头同表格页，工具栏的搜索改为「找一个节点设为中心」，右侧是节点数、关系数和「表格 / 图」切换。
- 画布左上：中心节点（点 × 回到入口节点）和深度 1 / 2 / 3。没有中心时显示当前范围里连接最多的 30 个实体作入口。
- 画布右上：撤销、重做（只在本页内）、筛选（种类、关系的来源、只看 AI 添加）。
- 画布左下：种类图例和「i」（三种线的含义）；右下：放大、缩小、适应窗口。
- 右侧面板：选中节点的详情。实体可以直接改名称、别名、说明和属性；相连按关系和方向分组；证据是原文引文，点页码打开预览；历史可恢复。

## 演示的规则

- 节点颜色按种类（kg- 令牌），文献大小按库内被引数；中心节点有虚线外圈，选中节点有光晕和拖线手柄。
- 实线：手动添加；带圆点的实线：从原文整理；虚线：自动线索（引用、相似）。
- 悬停的关系变成强调色；AI 添加的关系在标签旁有 AI 标记。
- 修改立即保存，离开本页时留一个历史版本；状态栏写明这一点。
- 绘图用 Cytoscape.js（MIT）加 edgehandles、fcose 扩展，这里是静态示意，零件见 KnowledgeGraph。
