整页示例：项目资料。就是项目文件夹本身的整页版：左边文件夹树，右边选中文件的信息和预览。

## 区域

- 页头：「项目资料」和「i」，项目文件夹路径；右侧重新扫描、新建文件夹、「导入到此文件夹」。
- 左侧文件夹树（ss-tree-row--nested，用 --depth 缩进）：每个文件名后一个索引状态点（已解析、解析中、仅索引文件名、失败），悬停看原因。
- 右侧：文件名、「在知识库中查看」、用默认程序打开、⋯；属性表（位置、大小、索引、知识库里的整理状态）；正文预览。
- 状态栏：一行汇总（已索引几个、正在解析几个、几个只索引文件名、几个失败）。

## 演示的规则

- 不做分类、标签和筛选，资源管理器里看到的就是全部。
- 每个文件都在 ScienceScope 的数据目录里有副本和索引；不能解析的也能按文件名和位置找到。项目文件夹里不写任何管理文件。
- 「导入」= 复制到当前打开的子文件夹，再按同样的规则索引。
- 右键：用默认程序打开、在资源管理器中显示、在知识库图中查看、重新解析、整理卡片、重命名、移到回收站。
- 空文件夹用插画空状态（Illustrations「项目文件夹是空的」）。
