整页示例：设置。居中的大窗口盖在当前页面上，左边是分类，右边是内容，按 Esc 或右上角的按钮关闭。

## 区域

- 窗口 `ss-dialog--settings`：宽 `dialog-xl`，最高 760px。
  - 左边是 200px 宽的分类导航：通用、外观、模型与服务商、执行与批准、专家、数据与运行环境、快捷键；分隔线下面是「关于」和版本号。
  - 右边是内容区，最宽 720px。
- 「模型与服务商」页从上到下是：
  - 快速添加：服务商预设；
  - 已添加：服务商卡片（ProviderCard）；
  - 默认模型：对话，以及秘书与后台任务；
  - 请求与上下文：无响应时停止、上下文压缩门槛。
- 添加订阅、更新密钥都用一个小对话框完成。

## 演示的规则

- 设置是一个窗口，不占用整页。改了立即生效，没有保存按钮。
- 每个分区只放和它有关的设置，名称和说明不重叠、不溢出。
- 思考强度不放在这里。上下文长度和输出上限不让用户填。
- 「关于」页写版本、构建和数据目录。
