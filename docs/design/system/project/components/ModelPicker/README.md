模型选择：在输入框底栏里选模型和思考强度；列表按服务商分组，只列出当前模型支持的强度。

## 结构

触发按钮是底栏里的轻按钮，写「模型名 · 强度」，用 `data-pop` 打开一个 `ss-pop`，里面有两部分。

- `ss-models`（`role="listbox"`）：
  - 按服务商分组，组名用 `ss-menu__label`；
  - 每个模型是一个 `ss-model`（`role="option"`、`aria-selected`），里面是 `ss-model__name`（等宽）和 `ss-model__meta`（上下文长度、支持哪些思考强度）；
  - 不能用的模型加 `disabled`，meta 里写原因和去哪里解决，如「密钥无效，去设置里更新」。
- `ss-effort`：「思考强度」加一个 `ss-seg--sm`，只列出当前模型支持的档位。模型不支持思考时，整行隐藏。

## 规则

- 思考强度只在这里选，设置页里不再放。
- 上下文长度和最长输出由程序自动获取：先查模型目录，再按名称匹配，都没有就用默认值。不让用户填数字。
- 换模型时，如果新模型不支持原来的强度，就改成它支持的最接近一档，并显示在按钮上。
- 这里的选择只影响当前对话；新对话用设置里的默认模型。
