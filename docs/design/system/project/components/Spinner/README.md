进行中的转圈、上下文用量圆环和「正在思考」流光文字。

## 结构

- 转圈：`<span class="ss-spin"></span>`（14px），`ss-spin--md`（16px）。
- 用量圆环：`<i data-ring="34"></i>`，外圈细线，里面是按比例填充的扇形；80% 起变 `warn`，95% 起变 `danger`。提示里写具体数字，如「上下文已用 34%（4.4 万 / 12.8 万 token）」。
- 思考：`<span class="ss-shimmer">正在思考</span>`，只给正在思考的模型用。

## 规则

- 不显示进度条、百分比进度和批次计数；说清在做什么、用了多久就够。
- 不到 1 秒就结束的动作不显示转圈。
- 开启「减少动态效果」时，转圈变慢，流光停止。
