整页示例：收件箱。左边是待确认的条目，可以批量接受或拒绝；右边看内容和依据，再决定接受、修改还是拒绝。

## 区域

- 页头和资料库相同，选中「收件箱」标签。
- 批量工具条（`data-batch`）：
  - 平时是全选框、搜索和漏斗；
  - 勾选后换成「已选 N 条」、拒绝所选、接受所选和取消选择。
- 列表（List，两行版）：
  - 第一行是条目内容；
  - 第二行写类型（决定、背景、未决问题、偏好）、来源和所在的对话；
  - 悬停出现接受、拒绝和 ⋯；
  - 处理过的条目收进折叠的「已处理」分组。
- 右侧面板（Panel，440px）：
  - 内容：属性、正文、依据（引文和「定位到消息」）；
  - 底部：「第 1 条，共 3 条」，以及拒绝、修改后接受、接受。

## 演示的规则

- 每一条都能看到依据，依据能跳回原来的消息。
- 接受后自动转到下一条。
- 主按钮只有「接受」一个，其余用默认按钮。
- 处理过的条目不消失，收进「已处理」。
