## 结构

- 用交付文件同一种收起行（ss-files）：图标 waypoints、「本轮修改了知识库」、一句摘要（新增几个实体、几条关系，修改、删除各几项）。
- 展开后逐条列出（ss-rel__row），每条前是种类点，后面写依据（页码或「你在对话中说的」）；没有依据的标「缺证据」。超过 6 条时收起其余。
- 底部（ss-files__foot）：「在图中查看」（打开图视图，以这组修改为中心）和「撤回这组修改」。

## 规则

- 撤回前先把当前状态存成一个版本，所以撤回也能再撤回。
- 之后又被改过的记录不撤回，结果用提示条写明几条。
- 只读的回答不显示这一行。
- 撤回之后按钮变成「恢复这组修改」；撤回和恢复都是新的版本，所以可以来回切换。
