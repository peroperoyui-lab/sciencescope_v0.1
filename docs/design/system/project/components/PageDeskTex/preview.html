\subsection{指标合成}
经济韧性指数采用熵权法合成，第 $i$ 个城市的综合得分为
\begin{equation}
CI_i = \sum_{j=1}^{m} w_j \, x_{ij}
\end{equation}
其中 $w_j$ 由第 $j$ 项指标的信息熵 $e_j$ 确定。
\subsection{一致性与覆盖度}
% 阈值依据 Ragin (2008) 的建议
条件组合 $X$ 对结果 $Y$ 的一致性定义为
\begin{equation}
\mathrm{Cons}(X \le Y) = \frac{\sum_i \min(x_i, y_i)}{\sum_i x_i}
\end{equation}
一致性阈值取 0.85，案例频数阈值取 2~\cite{ragin2008}。

3　研究设计

本章采用模糊集定性比较分析（fsQCA）识别城市经济韧性的条件组态，并以面板回归检验结论的稳健性。

3.1　指标合成

经济韧性指数采用熵权法合成，第 i 个城市的综合得分为

CIi=m∑j=1wj xij(3-1)

其中 wj 由第 j 项指标的信息熵 ej 确定。

3.2　一致性与覆盖度

条件组合 X 对结果 Y 的一致性定义为

Cons(X≤Y)=∑i min(xi, yi)∑i xi(3-2)
