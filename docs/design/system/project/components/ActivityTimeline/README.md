行动时间线：模型做的每一步（思考、前导语、工具调用和结果）一行一个，点开看细节；专家、任务秘书和全局助手共用。

## 结构

`ss-act` 放在 `ss-msg__head` 和 `ss-msg__body` 之间，按发生顺序放下面这些内容。

- 动作行 `ss-act__row`，里面依次是：
  - 图标；
  - `ss-act__verb`，动词短语，如「读取文件」「运行命令」；
  - `ss-act__target`，文件路径或命令，等宽字体；普通文字加 `ss-act__target--text`；
  - `ss-act__end`，结果，如行数、条数、用时、+12 −3；
  - 能展开时加 `ss-act__chev`。
- 能展开的行写成 `<button data-toggle="next" aria-expanded="false">`，紧跟在它后面的元素就是细节。细节有三种：
  - `ss-act__detail`：命令输出、文件内容或改动，超过 200px 后滚动。可以加 `ss-act__detail-head`（完整命令和复制按钮）和 `ss-act__detail-foot`（退出码、工作目录）。
  - `ss-act__nest`：子步骤，如搜索命中的资料。
  - `ss-act__thinking`：思考内容，左侧一条细线，文字用 `muted`。
- 前导语 `ss-act__narr`：模型在两个动作之间说的话，用正文的颜色和字号，和动作行交替出现。
- 状态：
  - 失败用 `ss-act__row--fail`（`danger`），提醒用 `ss-act__row--warn`（`warn`）；
  - 系统自己做的事用 `ss-act__row--muted`，如整理较早的对话；
  - 进行中的一行用 `ss-spin` 代替图标，动词写成进行时。
- 收起与展开：
  - 回答结束后，整个时间线收成一行 `ss-act__summary`（如「用时 34 秒 · 读了 8 篇资料」），点开是 `ss-act__list`。
  - 消息头里的「全部展开」用 `data-toggle-all`，一次展开或收起全部。

## 规则

- 不隐藏任何工具调用。失败的调用也留在时间线里，并写清原因。
- 动词写用户能看懂的话，如「搜索资料库」「修改文件」。动作行上不显示工具的英文名和参数 JSON。
- 回答进行中时间线保持展开，完成后收成一行摘要。
- 每个动作只占一行，过长的路径和命令截断，展开后看全文。
- 图标从 Icons 卡片的「行动时间线」一组里选。
