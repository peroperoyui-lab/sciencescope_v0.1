这一版改了什么

所有主窗口页面现在用同一个左栏（build/shell/gen.py 生成），不再各页各写一份。

「编辑台」放在工作站下面，小窗图标表示它在独立窗口打开；窗口已开时点它切过去。

工作站右边的简报按钮打开工作站简报（和对话页头的项目置顶摘要同一个浮层）。

「数据库」改名「知识库」，数字是收件箱里等你确认的记忆条数。

对话行尾直接显示状态：转圈是运行中，「待批准」「失败」「排队」各有标记，没有状态时显示最后更新时间。折叠的项目里有对话在运行，项目行也转圈。

每个项目先列最近 5 个对话，其余收进「还有 N 个」。列表末尾「全部对话」，含已归档的对话；在全部对话页时它是选中状态。

底部是个人资料、全局助手、设置。
