整页示例：项目对话，由左侧栏、对话主区和右侧任务秘书面板组成，按 1536×900 绘制（约等于 1920 宽的屏幕开 125% 缩放）。

## 区域

- 顶部标题栏 `ss-titlebar`：logo、应用菜单、窗口按钮。底部状态栏 `ss-statusbar`。
- 左侧栏（Sidebar）：新对话、资料库、工作站、搜索，下面是项目树和独立对话。运行中的对话行尾显示转圈。
- 主区：
  - 页头（PageHeader）：对话标题、参与的专家头像，右侧是历史版本、任务秘书开关和 ⋯；
  - 下面是消息流和输入框（Composer）。
- 右侧面板（Panel）：任务秘书。它的消息同样用 Message 和 ActivityTimeline，底部是紧凑版输入框。

## 演示的规则

- 已结束的回答收成一行摘要；进行中的回答展开，显示每一步。
- 前导语、思考、工具调用和结果按顺序排在时间线里。
- 运行命令前停在批准卡片（ApprovalCard），状态行写「等待你的批准」和已经等了多久。
- 回答进行中，发送按钮变成停止。
- 执行方式、上下文圆环、模型和思考强度都在输入框底栏。
- 侧栏和秘书面板都能拖宽。
- 运行中的对话不能归档，菜单里写明原因。
