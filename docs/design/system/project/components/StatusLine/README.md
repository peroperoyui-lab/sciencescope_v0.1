状态行：回答进行中，消息下方用一行写清现在在做什么、这一步用了多久；出错时写清原因和下一步。

## 结构

`<div class="ss-status">` 里依次放：

- 图标或 `ss-spin`；
- 一句状态；
- `ss-status__time`，这一步已经用了多少秒；
- 需要时在最后放一个轻按钮。

## 各阶段

1. 已发送，等待模型响应（转圈）。
2. 正在思考：文字用 `ss-shimmer`；用户系统设置了减弱动效时，改成静态的 `muted`。
3. 正在运行某个命令或工具（转圈，写出命令或工具）。
4. 等待你的批准，或自动重试中：用 `ss-status--wait`（`warn`）。
5. 开始输出正文后，状态行隐藏，正文本身就是进度。

出错和停止：

- 失败用 `ss-status--fail`（`danger`），写清原因，再给一个能做的动作，例如：
  - 「模型 60 秒没有响应，已停止」，配「重试」；
  - 「服务商返回 401：密钥无效」，配「去设置」。
- 等待时长来自设置里的「无响应时停止」。
- 用户停止：用 circle-stop 图标，写「你停止了这次回答，已保留到目前的内容」。

## 规则

- 计时从当前这一步开始算。不显示 token 数，也不显示进度百分比。
- 回答完成后状态行消失，用时写进时间线的摘要。
- 错误写成人话，同时保留服务商返回的状态码，方便排查。
- 一条消息只有一行状态，不叠加。
