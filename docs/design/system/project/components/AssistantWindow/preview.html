悬浮球（48px，桌面上始终在最前，可拖动）
右键菜单是系统菜单：展开或收起、退出助手 规则

单击悬浮球展开或收起助手窗口；拖动超过 5px 才算移动，不触发展开。

助手窗口没有系统标题栏，拖动面板头移动；「收起为悬浮球」只隐藏窗口，不清除历史，也不停止正在运行的任务，停止用输入框的停止按钮。

启动时显示什么在设置的「桌面浮球与启动」里选：不打开、只显示浮球、显示浮球与助手对话；下次启动生效。

主窗口里点左栏底部的 sparkle，在右侧面板打开同一个助手对话。
