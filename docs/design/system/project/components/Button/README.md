按钮执行一个明确的动作，文字用动词写清做什么。

## 何时用

- 默认按钮 `ss-btn`：次要动作，如「取消」「测试连接」「导入材料」。
- 主按钮 `ss-btn--primary`：一个区域里最多一个，如「保存」「允许」「接受」。浅色主题是墨色实底，深色主题是绿色实底，颜色来自 `primary` 和 `on-primary`。
- 轻按钮 `ss-btn--ghost`：工具条、输入栏、提示条里的动作，以及页头里的选择器。
- 危险按钮 `ss-btn--danger`：只放在确认对话框里，如「删除」「移除」。
- 自动化按钮 `ss-btn--auto`：只用来表示自动化执行方式，不做别的用途。

## 结构

`<button class="ss-btn [修饰]" type="button"><i data-i="图标名"></i>文字</button>`

- 尺寸：`ss-btn--sm` 24px（工具条、输入栏），默认 28px，`ss-btn--lg` 32px（对话框主按钮、空状态）。
- 进行中：加 `aria-busy="true"`，把图标换成 `<span class="ss-spin"></span>`，文字改成进行时，如「测试中」。
- 禁用：`disabled`。旁边或提示里写明为什么不能用。
- 只有图标时改用 IconButton。

## 规则

- 文字两到四个字，写动作，不写「确定」「好的」「提交」。
- 图标放在文字前面，只在能帮助辨认时加。
- 一排按钮里，主按钮放最右；危险动作和取消分开放。
