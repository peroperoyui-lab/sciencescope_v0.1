整页示例：资料库。页头里只有一行标签；搜索、漏斗和排序在同一行；解析提示收起；点一下资料就在右侧预览。

## 区域

- 页头（PageHeader）：
  - 「资料库」、范围选择（当前项目）；
  - 七个标签：文献与资料、知识、模型与公式、主张与证据、记忆、收件箱、项目简报；
  - 右侧「导入材料」。
- 筛选栏（FilterBar）：搜索、漏斗（角标是生效的条件数）、排序和篇数；下面一行是可以删除的筛选标签。
- 提示条（Callout）：几篇资料的解析提示合成一条，点「查看」展开细节。
- 列表（List）：一行一篇资料，悬停出现两个图标和 ⋯，右键打开同一份菜单；正在解析的一行显示转圈。
- 右侧面板（Panel）：
  - 头部：打开原件、⋯、关闭；
  - 内容：属性表、这一篇的解析提示、正文预览。

## 演示的规则

- 页内只有一行标签，范围放进页头的选择器。
- 筛选条件收进漏斗弹层，不摊成一排下拉框。
- 多篇的提示收成一条，不逐篇堆叠；正文已经入库时写明「检索不受影响」。
- 不做单独的详情页：单击预览，双击打开原件。
