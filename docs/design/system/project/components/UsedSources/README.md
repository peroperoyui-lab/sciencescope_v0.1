## 结构

- 用交付文件同一种收起行（ss-files）：图标 book-open、「本轮用到的资料」、一句摘要（几份资料，其中几份经由知识库找到）。
- 展开后每份资料一行（ss-files__row）：引用编号（ss-used__label）、标题，后面是项目文件夹里的位置（或「全局资料」「项目导入的资料」）和用到的页码。
- 经由知识库找到的资料下面一行 ss-used__via：路径（如「csQCA —变体自→ QCA」）和「在图中查看」。

## 规则

- 只列读过的资料和在回答里引用了的检索结果；只搜到没用的不列。
- 点一行在应用内预览原文；「在图中查看」打开全局知识库的图并选中这份资料。
- 没有用到资料的回答不显示这一行。
