ScienceScope 的标志：放大镜圆环里一颗四角星，矢量版跟随文字颜色。

## 用法

- 写 `<i data-logo></i>`，换成 SVG（类名 `ss-logo`，默认 18px）。标题栏里配 13px、600 字重的「ScienceScope」。
- 颜色只用 `ink` 或 `accent`。
- 最小 16px；四周留白不少于标志宽度的四分之一。
- 安装包图标和对外材料用资源里的位图原件（assets/Logos）。

## 不要

- 不加阴影、描边、渐变或底板，不拉伸，不改比例。
- 不要用 `mix-blend-mode` 处理白底位图；界面里一律用矢量版，深色主题才不会出问题。
