整页示例：知识库（表格）。「数据库」改名「知识库」；资料、条目和实体都是节点，点一下在右侧看详情。

## 区域

- 页头（PageHeader）：
  - 「知识库」、范围选择（当前项目 / 全局知识库）；
  - 标签：文献与资料、实体、知识、模型与公式、主张与证据、代码，以及「记忆 ▾」（记忆、记忆收件箱、项目简报收进一个菜单，它们不进图）；
  - 右侧「导入」。
- 工具栏：搜索、漏斗（整理状态、只看 AI 添加或缺证据、标签）、排序；右侧一行结果（如「已整理 6 篇；1 篇是扫描件，没有文字」）和「表格 / 图」切换。
- 列表（List）：一行一份资料，第二行是作者、年份和位置（项目文件夹里的相对目录，或「全局」）；后面是整理状态标签和关系数。数据文件用数据集图标，标「仅索引文件名」。
- 右侧面板（Panel）：节点详情。属性表 → 论文卡片（每项带页码 ss-cite）→ 相连（按关系分组，ss-rel）→ 历史（可恢复到某一版）。

## 演示的规则

- 状态只写结果和下一步：已整理、整理中、等待整理、扫描件没有文字、仅索引文件名；不显示 token、批次或百分比。
- 卡片每项都能点页码在预览里高亮原文；用户改过的项，重新整理时不覆盖。
- AI 写入且没人改过的关系带 AI 标记，悬停说明谁在哪次对话里依据哪段原文写的。
- 相似是线索，不是结论；说明放在「i」里。
