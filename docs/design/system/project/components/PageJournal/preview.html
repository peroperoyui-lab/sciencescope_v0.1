做了什么

把 S1（18 个二级指标）和 S4（24 个）的指标体系逐项对照，合并成 26 个二级指标，分经济、社会、生态、基础设施四类。15 个是两篇共有的，另外 11 个按研究区域的数据可得性取舍。

决定

  • 指标口径以 data/indicators.csv 为准；
  • 负向指标（失业率、PM2.5 年均值）先取倒数再标准化；
  • 权重用熵权法，稳健性检验再换 CRITIC。
