ScienceScope 是本地的研究助手：几位 AI 专家和用户一起读文献、做分析、写论文。界面是一张安静、紧凑，看得见每一步的研究工作台：内容在前，界面退后。

## 内容与语气

- 用「你」称呼用户。专家以自己的名字说话（「主专家」「任务秘书」），应用不自称「我们」。
- 句子要短，先说结果。按钮写两到四个字的动词，如「导入材料」「测试连接」「允许」；不写「确定」「提交」「好的」。
- 状态写结果和下一步，例如「连接正常 · 820 ms」「密钥无效，请重新填写」「模型 60 秒没有响应，已停止」。用户没有要求时，不显示 token 计数、批量进度或模型的原始输出。
- 说明放进 ⓘ（`ss-info`）或提示气泡。状态、错误和数据始终留在界面上。
- 空的分组整组隐藏，不写「暂无置顶」。没做完的功能用开关藏起来，不写「即将推出」。不要把示例数据当成真实数据展示。
- 中文和英文、数字之间加一个空格：「deepseek-v4-pro · 中」「60 秒」「1.2 GB」。时间写成「16:25」或「10-13 16:20」。
- 不用感叹号、emoji 和营销用语。
- 界面是中英双语，每一条新文案都要有英文版本。

## 颜色

- 只用 `tokens.json` 里的颜色令牌，组件里不写十六进制值。每个令牌的说明写了它的用途和可以放在哪些底色上。
- 底色分四层：
  - `paper`：主内容区；
  - `side`：左侧栏、设置导航和标题栏；
  - `raised`：输入框、卡片、菜单和弹层；
  - `sunken`：代码、用户消息气泡和细节框。
- 交互状态用 `hover`、`press`、`selected`。持续的选中状态用 `selected`，不用 `press`。
- 文字分四级：
  - `ink`：标题和正文；
  - `ink-2`：次要正文和图标；
  - `muted`：元数据、说明和占位符；
  - `faint`：只用于禁用和装饰，不能用于需要阅读的文字。
- 边框：
  - 分隔线和卡片边框用 `line`；
  - 输入框和次要按钮的边框用 `line-strong`；
  - 复选框边框用 `muted`。
  - 页面上的卡片靠边框区分，不加阴影。
- 品牌绿 `accent` 用在链接、选中标签的下划线、开关、滑块、头像、引用编号和聚焦环上。浅底用 `accent-soft`，浅底上的文字用 `accent-ink`。一屏里大面积的绿色只能出现在少数位置。
- 主按钮和发送按钮用 `primary`：浅色主题是墨色，深色主题是品牌绿；上面的文字用 `on-primary`。一个区域最多一个主按钮。
- 状态色要配图标或文字，不能只靠颜色：
  - `ok` 表示成功，和品牌绿是同一个颜色；
  - `warn` 系列表示提醒、等待批准和重试；`warn-soft` 浅底上的文字改用 `warn-ink`；
  - `danger` 系列表示错误、失败和删除。
- `auto` 系列只表示「自动化」执行方式，不表示错误。它和 `danger` 色相接近，所以自动化总是带闪电图标和「自动化」三个字。
- 提示气泡用 `tooltip` 和 `on-tooltip`，对话框背后的遮罩用 `scrim`。
- 浅色和深色主题使用同一组令牌名。组件只引用令牌，不按主题写分支。

## 字体

- 界面和正文用 `sans`（Noto Sans SC，应用自带字体文件）；命令、路径和代码用 `mono`。
- 界面文字：
  - 默认用 `t-ui`（13/20）；
  - 按钮、当前项和列表标题用 `t-ui-strong`；
  - 元数据和说明用 `t-small`（12/18）；
  - 分组标题用 `t-label`；
  - 时间、徽标数字和快捷键用 `t-caption`（11/16）。
- 对话消息和文档预览用 `t-body`（14/22），正文里的强调用 `t-body-strong`。命令和路径用 `t-mono`，消息里的代码块用 `t-mono-body`。
- 标题：
  - 页头里的页面标题用 `t-title`（15/22）；
  - 面板、对话框和设置分区的标题用 `t-heading`（14/20）；
  - `t-display`（20/28）只用在首页问候、空状态和关于页，一屏最多一处。
- 字重只用 400、500、600。不用小于 11px 的字。
- 行高按字号表来，不额外加大。段落之间 8px，列表项之间 2px。数字列用等宽数字。

## 间距、尺寸和密度

- 间距只用 `sp-2` 到 `sp-40`：
  - 行内元素之间用 `sp-4` 到 `sp-8`；
  - 控件组之间用 `sp-12` 到 `sp-16`；
  - 分区之间用 `sp-20` 到 `sp-24`；
  - `sp-32`、`sp-40` 只给空状态、首页和关于页留白。
- 控件高度：
  - `h-sm`（24px）：工具条、输入栏和列表行里的控件；
  - `h-md`（28px）：默认高度；
  - `h-lg`（32px）：对话框主按钮和空状态里的按钮；
  - `h-row`（36px）：单行列表的行高。
- 窗口骨架：
  - 标题栏 `titlebar`，页头 `header`，状态栏 `statusbar`；
  - 左侧栏 `sidebar`，可以在 `sidebar-min` 到 `sidebar-max` 之间拖动；
  - 右侧面板 `panel`，可以在 `panel-min` 到 `panel-max` 之间拖动；
  - 对话列最宽 `chat`。
- 对话框宽度：确认用 `dialog-sm`，表单用 `dialog-md`，内容较多时用 `dialog-lg`，设置窗口用 `dialog-xl`。
- 每一页都按 1536×900（1920 宽的屏幕开 125% 缩放）检查。界面要紧凑：先用小一档的间距，确实挤了再放大。

## 圆角、阴影和层级

- 圆角：
  - `r-xs`：标签、引用编号、行内代码和菜单项；
  - `r-sm`：按钮、输入框、列表行和导航行；
  - `r-md`：菜单、弹层、提示条、批准卡片和服务商卡片；
  - `r-lg`：对话框、命令面板和用户消息气泡；
  - `r-xl`：只用于输入框外框；
  - `r-full`：头像、圆点、开关、发送按钮和筛选小标签。
- 阴影：
  - `shadow-1`：输入框，以及分段控件的当前项、开关滑块这类贴着表面的元素；
  - `shadow-2`：菜单、弹层、提示气泡和通知；
  - `shadow-3`：对话框和命令面板。
- 层级从低到高依次是 `z-sticky`、`z-splitter`、`z-pop`、`z-dialog`、`z-toast`、`z-tip`，提示气泡永远在最上层。
- 禁用的控件整体使用 `o-disabled` 透明度，并在旁边或提示里写明为什么不能用。

## 动效

- 悬停、按下和颜色变化用 `--t-fast`（120ms），弹层、对话框、通知和开关用 `--t-med`（160ms），缓动统一用 `--ease`。
- 不做弹跳、缩放进场和视差。拖动分栏要跟手，不加过渡。
- 用户在系统里减弱了动效时，过渡时长归零，转圈放慢，「正在思考」的流光变成静态文字。

## 图标与标志

- 全站只用 Lucide 线性图标：16px（`icon`），小号 14px（`icon-sm`），线宽 1.75，颜色跟随文字。
- **替换说明**：旧原型的 38 个手绘线性图标已整体换成 Lucide 1.49.0（ISC 许可）。原来的图标覆盖不了时间线、批准、筛选等新含义，混用两套会让线宽和比例不一致。
- 一个含义只对应一个图标，含义表见 Icons 卡片（共 107 个，分六组）。新增含义时，先加进这张表再使用。
- 不用 emoji，不混用其他图标库，不自己画图标。只有图标的按钮必须带提示。
- 标志的原件是 `assets/Logos` 里的位图（白底，墨色 #222529）。界面里用矢量版：写 `<i data-logo></i>`，它是从原件描出来的单色图形，颜色跟随文字，只用 `ink` 或 `accent`。
- 安装包图标和对外材料用原件。

## 交互规则

- 弹层：
  - 菜单、弹层和提示都锚定在触发它的元素旁边，空间不够时翻到另一侧；
  - 点外面或按 Esc 关闭，焦点回到触发元素；
  - 同一时间只开一个弹层。
- 每一行悬停时最多出现两个图标按钮，其余收进 ⋯。整行右键打开同一份菜单，不出现浏览器自带的右键菜单。
- 左侧栏和右侧面板都能拖宽，双击恢复默认宽度，宽度记在本机。右侧面板推开主区域，不盖在内容上。
- 每页只有一行页内标签，范围放进页头左侧的选择器。筛选条件收进漏斗弹层，生效的条件显示成可以删除的小标签。
- 多条提醒收成一条，细节点开再看，不逐条堆叠。
- 列表单击在右侧预览，双击或 Enter 打开原件，不做单独的详情页。
- 对话：
  - 发送和停止是同一个按钮，停止立即生效，已经生成的内容保留；
  - 专家、任务秘书和全局助手共用同一套消息和行动时间线，每个工具调用都看得见；
  - 执行方式分三档：请求批准（新对话默认）、常规、自动化；
  - 思考强度在输入框底栏选，模型的上下文和输出上限由程序自动获取，不让用户填数字。
- 设置是居中的大窗口，按 Esc 关闭，改了立即生效，没有保存按钮。
- 全程能用键盘操作：
  - Ctrl K 搜索和命令，Ctrl N 新对话，Ctrl , 设置，Ctrl J 打开或关闭任务秘书；
  - Enter 发送；Esc 先关闭最上层的弹层或窗口，没有弹层时停止回答；
  - F2 重命名，Alt ← 返回。

## 可读性

- 文字在说明里写到的每种底色上都不低于 4.5:1，图标和表示状态的边框不低于 3:1，浅色、深色两套主题都要满足。
- 键盘焦点是 2px 的 `focus` 实线，外扩 2px，在所有表面上不低于 3:1。不要去掉焦点环。
- `muted` 在 `paper`、`side`、`raised`、`sunken`、`hover`、`selected` 上都不低于 4.5:1；`press` 只在按下的一瞬间出现，上面不放 `muted` 文字。
- 已知的例外：
  - `line-strong` 和底色只有约 1.4:1，所以输入框总要配标签或占位符，放在 `raised` 底上，聚焦时由 `focus` 标出；
  - 深色主题里 `auto` 实底和 `paper`、`raised` 只有约 2.4:1 和 2.1:1，自动化按钮靠 `on-auto` 白字和闪电图标识别。

## 使用组件

- 组件是 HTML 结构加 `ss-` 开头的类名，不是 React 组件。每个组件卡片的说明写了结构、什么时候用和规则。
- 页面依次加载 `tokens.css`、`components/bundle.css`、`components/bundle.js`，在 `<html>` 上设置 `data-theme="light"` 或 `data-theme="dark"`。
- `bundle.js` 提供 `SS.mount(root)`，负责：
  - 把 `<i data-i="图标名">`、`<i data-logo>`、`<i data-ring="34">` 换成 SVG；
  - 接上 `data-menu`、`data-pop`、`data-ctx`、`data-tip`、`data-toggle`、`data-batch`、分隔线和对话框的行为。
- 应用（`app/ui/`）用 Preact 组件输出同样的结构和类名，行为照 `SS` 的示例实现，不在应用里加载 `bundle.js`。
