## 3. 接入你自己的 API

设置（左下角齿轮）→ 模型与 API → 添加服务：

1. 填名称、OpenAI 兼容的接口地址、密钥；需要的话加自定义请求头。
2. 点"获取模型列表"，选模型；可以填上下文窗口、最大输出、思考强度。
3. 设为默认。

主专家、各位专家、任务秘书、全局助手可以分别在各自的设置页选模型；不选就用默认模型。

## 4. 建议的全流程（按顺序，每步记下感受）

1. **新建项目**：
   - 名称和研究目标；
   - 工作文件夹：可以选一个已有文件夹；
   - Python 环境：默认"内置 · 科学分析"。第一次会下载 Python 和分析包，需要一些时间。
2. **资料库**：侧栏"数据库" → 导入几篇 PDF / DOCX → 搜索一个你熟悉的说法 → 打开材料详情看段落和页码。
3. **主对话**：
   - 问一个和资料有关的问题，看回答是否引用了 `[S1 p.3]` 这样的出处，点出处能否跳到原文；
   - 在回答里划选一段加标记，再追问。
4. **有序讨论**：
   - 输入框左下"工作"→"有序讨论"，选两位专家和一位审核；
   - 问一个需要不同角度的问题，看各专家的回答和审核；
   - 采纳审核后，让主专家接着回答。
5. **任务秘书**：
   - 右上"会议秘书"打开秘书栏，问它目前的进展；
   - 让它起草下一步给主专家的指令，填入主对话；
   - 会议"…"菜单 → 对话纪要，看纪要是否准确。
6. **分析**：让主专家用 Python 读你的数据（CSV / Excel），做描述统计并出图；图应显示在回答下方。
7. **自动化**：输入框的执行菜单选"自动化"，给一个三五轮能完成的目标，例如"整理数据、出两张图、把结论写进项目日志"；中途试一次暂停和继续。
8. **工作站**：
   - 看计划、日志、导图是否被更新；
   - 试试历史版本的查看和恢复；
   - 把一篇稿件的两个版本拖进左栏"文献版本管理"，看秘书写的版本说明和比较页。
9. **记忆**：过一段时间后看资料库的"记忆收件箱"，接受一两条，再看"项目简报"。
10. **全局助手**：用户栏的全局助手，问"我的项目都进行到哪里了"。
11. **关闭再打开**：确认对话、纪要、计划都还在。

## 5. 反馈怎么写最有用

每个问题一条，写清楚：

- 在哪一步、做了什么；
- 期望看到什么，实际看到什么；
- 截图（界面问题）或日志文件夹（报错、卡住）；
- 严重程度：
  - **挡路**：做不下去了；
  - **难用**：能做但别扭；
  - **建议**：可以更好。

也欢迎写整体感受，比如哪个功能你会天天用、哪个用不上、和你现在的研究方式哪里对不上。
