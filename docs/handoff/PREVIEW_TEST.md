# ScienceScope 预览版首测指南

给用户本人的首测。目的：用你自己的 API、自己的研究材料，把完整流程走一遍，记下哪里不顺、哪里坏了、哪里和你预期不一样。

预览版装在 `<预览安装目录>`，从开始菜单或桌面快捷方式启动，不用自己再装。

## 0. 第四个预览包（alpha 前首测）

第四个预览包由 Codex 覆盖安装到同一个目录 `<预览安装目录>`，安装前的数据另外备份了一份（位置见第 2 节）。正式发布前旧对话和旧版本记录不保证能打开，有问题照实记下即可。和第三轮相比，几乎每一页都换了，这一轮请按第 4 节的全流程完整走一遍，重点看下面几处：

1. **首页**：一屏放下。上面是插画和问候，选了项目时有一句进度和「继续：最近的对话」「看计划」；下面是「从这里开始」四张卡片，点了只填进输入框，不会自己发出。离开一个项目后过一会儿，不选项目的首页会换成秘书按那个项目写的进度和卡片。再往下是「继续上次的工作」（「继续写作 ⌄」可选在编辑台打开、在资源管理器中显示、用默认程序打开）和常用学术站点。
2. **知识库**：所有项目共用一个知识库。表格页看资料和实体，图页看它们之间的连线。回答下面会写「本轮用到的资料」，回答改了知识库时会写「本轮修改了知识库」，可以撤回。工作站「项目文件夹」卡片右上角进入项目资料页，能看到每个文件的索引状态。
3. **编辑台**：独立窗口，打开项目里的 docx、md、tex、pdf。
   - 直接在页面上改；
   - 「批注与索引」一栏里有批注和索引；
   - 划选一句可以让专家改写；
   - 「审阅 → 比较」两页并排比较两个版本；
   - 底栏「版本树」看这份文稿的所有版本和分支，详情里能改名、改层级、改分支名、写标记，右键可以设为重点、从某一版开始编辑；
   - 右侧「对话」「来源」两栏是这份文稿绑定的对话，和这段对话用到的资料。
4. **从对话进入编辑台**：专家觉得初稿成形时会提议进入编辑台，可以选接着这段对话，或者开一个分支对话。编辑台里对话的回答可以「插入到正文光标处」或「贴到选中的句子上当批注」。
5. **工作站**：计划、导图、日志、项目文件夹、版本树都是新页面。
6. **任务秘书**：秘书面板输入框上方有两句常用的话，点一下直接发出。
7. **设置**：每一页都换成了新样式，改了立刻保存，包括工具、技能、MCP 服务器、编辑台、数据与备份（导出全部数据）、关于（自动检查更新）。
8. **观感**：各页面的空状态有插画；文字和行距比以前紧凑。哪里挤、哪里看不清，截图告诉我。

- SHA-256：`9f7602d1b2a0770ae00498501057532673af546779be3a436fdfac36728da222`。
- 已覆盖安装到 `<预览安装目录>`；原项目、对话记录、服务商和设置核对保留，单次连接测试通过。数据备份见第 2 节。

- 不需要先装 Node。Python 和分析包在第一次准备内置环境时下载，本地检索模型在开启本地语义检索时下载。

## 2. 数据和日志在哪里

- 全部数据：`<预览安装目录>\data\`。覆盖安装和默认卸载都不会删除它；卸载时只有勾选"删除应用程序数据"，才会连数据一起删除。
- 2026-10-20 第三轮覆盖安装前的完整备份：`<预览备份目录>\data\`。已核对 50,144 个文件的全部相对路径和大小，总计 1,781,644,543 字节；数据库、设置和凭据文件 SHA-256 一致。旧的 20261017 备份未改动。备份含凭据，请保留在本机。
- 2026-10-17 覆盖安装前的完整备份：`<预览备份目录>\data\`。已核对全部 48,152 个文件的路径和大小，总计 1,649,590,222 字节；数据库、设置和凭据文件另经 SHA-256 核对一致。备份含凭据，请保留在本机。
- 日志：`<预览安装目录>\data\logs\`。`desktop-host.log` 是这次运行的日志，`desktop-host.previous.log` 是上一次的，所以出问题后重开软件，上一次的记录还在。反馈问题时附上 `logs` 文件夹，不要附 `secret` 文件夹。
- 密钥只存在 `data\secret\credentials.yaml`。
- 第一次准备 Python 环境后，数据目录会增加 1–2 GB（Python 本体、分析包和缓存）。

## 3. 接入你自己的 API

设置（左下角齿轮）→ 模型与服务商：

1. OpenCode Go 或 DeepSeek：在「快速添加」点「添加」，粘贴密钥，点「测试并保存」。
2. 其他兼容 OpenAI 或 Anthropic 接口的服务：点「其他兼容服务」，填名称、接口格式、地址、密钥和模型 ID（可以点「获取模型列表」）；需要的话加附加请求头。
3. 在「默认模型」里选对话默认用的模型。

主专家、各位专家、任务秘书、全局助手可以分别在各自的设置页选模型；不选就用默认模型。

## 4. 建议的全流程（按顺序，每步记下感受）

1. **新建项目**：
   - 名称和研究目标；
   - 工作文件夹：可以选一个已有文件夹，里面放几篇 PDF、一份 docx 稿件和一份数据表；
   - Python 环境：默认"内置 · 科学分析"。第一次会下载 Python 和分析包，需要一些时间。
2. **项目资料与知识库**：
   - 工作站「项目文件夹」卡片右上角进入项目资料页，看每个文件的索引状态；
   - 侧栏「知识库」搜一个你熟悉的说法，打开资料看段落和页码；
   - 切到图页，看资料和实体之间的连线。
3. **主对话**：
   - 问一个和资料有关的问题，看回答是否引用了 `[S1 p.3]` 这样的出处、点出处能否跳到原文；
   - 看回答下面的「本轮用到的资料」；
   - 在回答里划选一段加标记，再追问。
4. **有序讨论**：
   - 输入框左下"工作"→"有序讨论"，选两位专家和一位审核；
   - 问一个需要不同角度的问题，看各专家的回答和审核；
   - 采纳审核后，让主专家接着回答。
5. **任务秘书**：
   - 打开秘书面板，问它目前的进展，试试输入框上方的常用的话；
   - 让它起草下一步给主专家的指令，填入主对话；
   - 对话"…"菜单 → 对话纪要，看纪要是否准确。
6. **分析**：让主专家用 Python 读你的数据（CSV / Excel），做描述统计并出图；图应显示在回答下方。
7. **编辑台**：
   - 让主专家帮你起草或修改那份 docx，等它提议进入编辑台（也可以从侧栏「编辑台」直接打开）；
   - 在页面上直接改几处，Ctrl+S 写回项目文件；
   - 划选一句让专家改写，看它有没有加原文里没有的说法；
   - 加一条批注、一条索引；
   - 存一个版本，再用「审阅 → 比较」看两版差别；
   - 打开版本树，给一个分支改名，从旧版本开始编辑，看新分支长出来。
8. **工作站**：看计划、日志、导图是否随对话更新；试试历史版本的查看和恢复。
9. **首页**：离开项目回到首页，过一会儿看秘书写的进度和卡片是否说得对，点一张卡片看它在哪个项目里开新对话。
10. **记忆**：过一段时间后看知识库里的"记忆收件箱"，接受一两条，再看"项目简报"。
11. **全局助手**：用户栏的全局助手，问"我的项目都进行到哪里了"。
12. **设置**：浏览每一页；在「数据与备份」试一次导出全部数据。
13. **关闭再打开**：确认对话、纪要、计划、编辑台里的文稿和版本都还在。

## 5. 反馈怎么写最有用

每个问题一条，写清楚：

- 在哪一步、做了什么；
- 期望看到什么，实际看到什么；
- 截图（界面问题）或日志文件夹（报错、卡住）；
- 严重程度：
  - **挡路**：做不下去了；
  - **难用**：能做但别扭；
  - **建议**：可以更好。

也欢迎写整体感受，比如哪个功能你会天天用、哪个用不上、和你现在的研究方式哪里对不上。
