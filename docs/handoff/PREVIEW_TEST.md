# ScienceScope 预览版首测指南

给用户本人的首测。目的：用你自己的 API、自己的研究材料，把完整流程走一遍，记下哪里不顺、哪里坏了、哪里和你预期不一样。

预览版装在 `<预览安装目录>`，从开始菜单或桌面快捷方式启动，不用自己再装。

## 0. 第三轮预览（阶段 1 收尾）

第三个预览包由 Codex 覆盖安装到同一个目录 `<预览安装目录>`，安装前的数据另外备份了一份（位置见第 2 节）。正式发布前旧对话不保证能打开，有问题照实记下即可。这一轮请重点看下面几处，第 4 节的全流程照常走一遍：

1. **对话页**：
   - 连续的命令合成一组，批准不再单独占一行，是那一步的状态；
   - 交付的文件收成一行，可以展开；
   - 设置 → 个人资料与常规里能调对话行距和侧栏字号；
   - 有序讨论里每位专家在作答时是一个固定高度的状态框；
   - 日志详情点一下就能直接改。
2. **执行方式**只剩「请求批准」和「常规」，自动化和目标已经删掉。
3. **总是允许**：批准卡片上点「总是允许 ▾」，选一个范围（这条命令、以某个词开头的命令、这个文件夹、这个包）。之后同类操作直接运行，规则只在这个项目里生效。设置 → 运行环境 →「总是允许的操作」可以删掉规则。
4. **看图**：让专家看 PDF 某一页的图或公式，步骤里能看到它看的图片，点击放大。模型不支持看图时会提示换模型。
5. **回答进行中插入**：回答还没结束时发的消息先进队列，点「现在插入」，它会交给正在进行的回答，不打断它。
6. **同时 @ 几位专家**：一条消息里 `@方法学家 看识别策略 @统计审稿人 看标准误`，两位同时作答，各自只回应自己那一段。
7. **技能**：问主专家有哪些内置技能（查资料并引用、修改工作区、交付文件、用 Python 分析），让它分析一份表格并交付一张图。技能和 MCP 服务器的设置页还没做。
8. **图标和关于页**：开始菜单和任务栏是纸色底板、墨色标志的图标，欢迎页有插画，设置 → 关于 ScienceScope。
9. **观感**：对话页和设置页是新界面；数据库、工作站、导图等页面还是旧样式，会在阶段 2 逐页重做。

## 1. 安装包（需要重装时用）

- 安装包：`<工作区>\.sciencescope-local\dist\ScienceScope_1.0.0-alpha.0_x64-setup.exe`，95,429,910 字节（91.01 MiB），2026-10-17 从集成基线 `681be09` 加入覆盖安装清理后重新打包；产品名、identifier 和版本号保持不变。
- SHA-256：`618a45ffa86e3db26bca9a688d2135efb2f2acc91d24bcf18f3a6e8e35e3ff29`。
- 此新包尚未安装到用户的 `<预览安装目录>`。用户当前安装及其数据、备份均保持原状，待明确安排后再覆盖。
- 双击安装，可以选安装位置。安装包没有签名，Windows 可能提示"Windows 已保护你的电脑 / 未知发布者"：点"更多信息"→"仍要运行"。
- 本机 H 盘是 USB 外接 WD40EFRX 机械硬盘。R6a-5 独立测试产品全新安装实测 2 分 41.5 秒，覆盖安装 4 分 8.2 秒，没有先运行旧卸载器。请等安装器自己结束再启动。
- 新包覆盖前按固定清单清理旧程序文件，保留 `data\` 和其他用户文件。测试产品覆盖与全新安装均为 9,697 个程序文件、356.18 MiB，逐文件内容哈希一致；329 个原有数据文件及额外放置的用户文件完整保留。
- 用户当前安装仍是 R6a-4 的覆盖结果（31,030 个程序文件、690.29 MiB）；这次只验证独立测试产品，没有清理用户安装中的旧文件。
- 不需要先装 Node。Python 和分析包在第一次准备内置环境时下载，本地检索模型在开启本地语义检索时下载。

## 2. 数据和日志在哪里

- 全部数据：`<预览安装目录>\data\`。覆盖安装和默认卸载都不会删除它；卸载时只有勾选"删除应用程序数据"，才会连数据一起删除。
- 2026-10-17 覆盖安装前的完整备份：`<预览安装目录>-backup-20261017\data\`。已核对全部 48,152 个文件的路径和大小，总计 1,649,590,222 字节；数据库、设置和凭据文件另经 SHA-256 核对一致。备份含凭据，请保留在本机。
- 日志：`<预览安装目录>\data\logs\`。`desktop-host.log` 是这次运行的日志，`desktop-host.previous.log` 是上一次的，所以出问题后重开软件，上一次的记录还在。反馈问题时附上 `logs` 文件夹，不要附 `secret` 文件夹。
- 密钥只存在 `data\secret\credentials.yaml`。
- 第一次准备 Python 环境后，数据目录会增加 1–2 GB（Python 本体、分析包和缓存）。

## 3. 接入你自己的 API

设置（左下角齿轮）→ 模型与服务商：

1. OpenCode Go 或 DeepSeek：在「快速添加」点「添加」，粘贴密钥，点「测试并保存」。
2. 其他兼容 OpenAI 或 Anthropic 接口的服务：点「其他兼容服务」，填名称、接口格式、地址、密钥和模型 ID（可以点「获取模型列表」）；需要的话加附加请求头。
3. 在「默认模型」里选对话默认用的模型。

主专家、各位专家、任务秘书、全局助手可以分别在各自的设置页选模型；不选就用默认模型。

## 4. 建议的全流程（按顺序，每步记下感受）

1. **新建项目**：
   - 名称和研究目标；
   - 工作文件夹：可以选一个已有文件夹；
   - Python 环境：默认"内置 · 科学分析"。第一次会下载 Python 和分析包，需要一些时间。
2. **资料库**：侧栏"数据库" → 导入几篇 PDF / DOCX → 搜索一个你熟悉的说法 → 打开材料详情看段落和页码。
3. **主对话**：
   - 问一个和资料有关的问题，看回答是否引用了 `[S1 p.3]` 这样的出处，点出处能否跳到原文；
   - 在回答里划选一段加标记，再追问。
4. **有序讨论**：
   - 输入框左下"工作"→"有序讨论"，选两位专家和一位审核；
   - 问一个需要不同角度的问题，看各专家的回答和审核；
   - 采纳审核后，让主专家接着回答。
5. **任务秘书**：
   - 右上"会议秘书"打开秘书栏，问它目前的进展；
   - 让它起草下一步给主专家的指令，填入主对话；
   - 会议"…"菜单 → 对话纪要，看纪要是否准确。
6. **分析**：让主专家用 Python 读你的数据（CSV / Excel），做描述统计并出图；图应显示在回答下方。
7. **自动化**：输入框的执行菜单选"自动化"，给一个三五轮能完成的目标，例如"整理数据、出两张图、把结论写进项目日志"；中途试一次暂停和继续。
8. **工作站**：
   - 看计划、日志、导图是否被更新；
   - 试试历史版本的查看和恢复；
   - 把一篇稿件的两个版本拖进左栏"文献版本管理"，看秘书写的版本说明和比较页。
9. **记忆**：过一段时间后看资料库的"记忆收件箱"，接受一两条，再看"项目简报"。
10. **全局助手**：用户栏的全局助手，问"我的项目都进行到哪里了"。
11. **关闭再打开**：确认对话、纪要、计划都还在。

## 5. 反馈怎么写最有用

每个问题一条，写清楚：

- 在哪一步、做了什么；
- 期望看到什么，实际看到什么；
- 截图（界面问题）或日志文件夹（报错、卡住）；
- 严重程度：
  - **挡路**：做不下去了；
  - **难用**：能做但别扭；
  - **建议**：可以更好。

也欢迎写整体感受，比如哪个功能你会天天用、哪个用不上、和你现在的研究方式哪里对不上。
