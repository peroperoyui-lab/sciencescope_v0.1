# 桌面窗口与浏览器交接

## 已实现的原型行为

全局助手、独立快速聊天、导图、浏览器分离页用真正的独立浏览上下文打开。主窗口不加遮罩，可继续切项目、输入或阅读。原型先打开 about:blank，再写入同一份自包含应用内容，因此无需 Web 服务或外部依赖。

全局助手浮窗内可收起为球状入口，再次点击恢复原临时问答。工作站、数据库、项目条目等动作会激活并导航主窗口。导图编辑器保存后同步对应项目的预览，即使主窗口暂时切换到另一个项目，也按项目身份保存。

浏览器侧栏具有关闭、地址输入、前进、后退、刷新、引用和独立窗口按钮。地址变化有本次内存历史；显示内容为离线示例页，没有偷偷请求外部站点。系统浏览器打开是用户主动操作。

普通表单使用可拖动或可关闭的非模态面板，编辑计划／日志时仍可使用主工作区。窗口切换保留表单草稿，保存到打开编辑器时绑定的对象。

## 桌面版应接通的结果

- 全局助手是主窗口之外的桌面浮窗／浮球。按用户设置保持置顶、移动、贴边、恢复上次位置；浮球与面板切换保留当前会话。
- 浮球收起仅隐藏展示，不额外启动或销毁一份 Agent 宿主。用户操作可以唤醒主客户端并打开准确页面／项目／消息。
- 导图二级编辑器独立窗口，多窗口访问同一份项目状态；保存后对应项目预览刷新。窗口关闭时提供未保存内容的合理处理。
- 内置浏览器复用完整 DSH 或当前桌面组合可用的成熟能力；拥有标签页、前后退、重载、地址栏、下载与关闭。弹出窗口保持主应用可用。
- 打开文件、资源管理器、外部浏览器、默认程序由本地宿主接入；显示真实路径及文件打开失败原因。
- 正常退出收口当前应用创建的任务、监听器、辅助窗口和子进程；托盘驻留作为用户设置。读取外部已存在的程序不等于取得其生命周期所有权。

## 浏览器预览的边界

浏览器会决定是否允许弹窗、是否作为新标签打开、是否允许脚本调整尺寸。原型不能保证 OS 级 always-on-top、透明悬浮球、系统级快捷键和窗口无边框。弹窗被拦截时显示允许弹窗提示，不改成覆盖主界面的模态窗口。手动从页面目录打开“全局助手”页也可看到独立窗口入口。

这轮自动化验证使用 Chromium 的页面内容注入方式；运行环境阻止 file/http 页面导航，未修改环境策略。实际新窗口及其与主窗口联动已验证；OS 窗口行为、真实浏览器内核、Windows 默认程序和资源管理器需要本地验收。
