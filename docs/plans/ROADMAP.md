## 目标：1.0.0-alpha

在 Windows 上用候选安装包走完一次真实研究流程：导入资料进知识库 → 多位专家与用户讨论 → 秘书纪要 → 修改计划、导图、日志 → 在编辑台改稿、比较版本 → 退出、升级后数据完整。有安装包上的实测证据才算数。
