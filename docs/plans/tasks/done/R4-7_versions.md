## 目标

稿件和文献的每个版本都有地方放、有说明、能比较：
- 用户把新一版稿件拖进工作站，自动编号；
- 任务秘书对比上一版，写出"改了什么、对研究有什么影响、有什么待你决定"；
- 任意两个版本可以逐字词比较；
- 项目日志可以关联这些文件。

## 和旧版不同的地方

1. **原件存放位置**：
   - 版本原件放在 ScienceScope 自己的数据目录：项目目录下的 `versions/`（原则 1），不写进用户绑定的外部项目文件夹（旧版写在 `paper_versions/`）。
   - 说明 Markdown 和原件放在一起（`<原件名>.notes.md`），不打开应用也能读。
2. **能整理的格式**：
   - 用 R4-1 的解析器提取文字，所以 PDF、DOCX、Markdown、LaTeX、纯文本都能整理说明、都能比较。
   - 旧版只支持文本格式，并且有 40000 字符上限。按原则 4 不设上限：比较结果完整交给秘书，原文过长时，秘书用工具分段读取。
3. **工作站左栏**：
   - 恢复旧设计，左栏是"文献版本管理"。
   - 历史版本（R4-11）在左栏只是临时位置，现在改由计划、日志、导图各自的"历史版本"按钮进入，置顶摘要（P07）里的最近版本保留。这些入口 R4-11 已经做好。

依据 `reviews/REVIEW_2026-10-07.md` §5 和 `docs/plans/IDEAS.md`"写作与编辑工作台"。

- 在 `docs/architecture/CORE_MODEL.md` 新增一节"引用"，定义一种引用对象，覆盖：

## 7a 版本存储与导入（P13）

- **资源**：工作区资源 `versions`，按项目划分。数据库只存版本组、版本记录，以及版本和文件的对应关系，用新迁移（015 起）。
  - **版本组**：一篇稿件或一份文献。
  - **版本**：版本号（自动递增）、原件文件名、导入时间、导入者、比较基线（默认上一版，可以改）、说明状态。
- **导入**：
  - 工作站左栏的拖入区和"添加文件"。选择已有版本组或新建一组；同一批的多个文件可以调整顺序。
  - 原件保存完成后立刻可以打开，说明不需要等。
- **操作**：
  - 打开原件（默认程序）；
  - 在资源管理器中定位；
  - 预览（复用 R4-2 的预览栏）；
  - 重命名版本组；
  - 删除版本（进回收站，确认后执行）。
- **AI 访问**：通过现有的 `workspace_read` / `workspace_edit` 访问 `versions`（列出、读取提取文字并分页、编辑说明），不新增按角色区分的工具（原则 2）。
- **界面**：工作站左栏"文献版本管理"按旧结构复刻：
  - 每组下列出各版本：版本号、导入时间、说明状态、操作；
  - 秘书处理状态只显示结果：等待整理 / 整理中 / 已完成 / 整理失败（可重试）。

## 7b 版本说明（P14）

- **秘书整理**：
  - 导入后，如果项目开了"自动整理说明"（旧版 `autoOrganize`，默认开），用 R4-4 的后台发言入口让秘书写说明；也可以手动点"整理说明"。
  - 输入包括：比较基线和当前版本的提取文字差异（完整）、当前研究上下文（纪要的目标与待办、计划）、说明模板。
  - 说明分三部分，分开写：实际文件变化、秘书的解释、待用户决定的建议（P14 的检查项）。
- **模板**：设置"任务秘书"页加"文献版本整理"一节，编辑说明模板（Markdown，旧版有默认模板，沿用）。
- **说明页 P14**：
  - 显示当前版本、比较基线、生成时间；
  - 正文是渲染后的 Markdown；
  - 可以编辑补充（保存为新的修订，历史版本可恢复）、打开 MD 文件、换比较基线后重新整理、引用说明到当前对话（加入输入框材料，复用 R4-2）、跳到实际差异（7c）。
- **随总结更新工作台**：R4-4 的"随总结更新工作台"补上"稿件版本说明"一项，仍是"关闭 / 直接更新"两档，默认关闭。
- 说明的每次修改都留历史版本（原则 3）。

## 7c 版本比较与日志关联文件（P09、P12）

- **比较页 P09**：
  - 选旧版本和新版本，并排或统一视图；
  - 显示增加、删除、替换；按变化上下跳转；
  - 打开两个原件；
  - 显示这次修改的说明。
  - 字词级比较：中文按词切分（`Intl.Segmenter`，粒度为词），再做序列差异。可以加 `diff`（jsdiff，BSD 许可）依赖。
  - 状态：可比较 / 无变化 / 仅原件可打开（解析失败时）。
- **恢复**：在比较页把旧版本"另存为新版本"，原件复制成新的一版，不覆盖任何已有版本；恢复前后的记录都在。不做片段级恢复。
- **日志关联文件（P12）**：
  - 日志条目可以关联版本或项目文件（统一引用格式）；
  - 日志详情页有"文件列表"一栏，点击打开；
  - 秘书整理日志时可以写入关联。

## 顺带：模型下载源可选（用户 2026-10-12）

- 默认仍是官方源。
  - Python 包镜像（R4-8）已经可选，默认官方，不变。
  - 本地检索模型目前固定从 Hugging Face 下载，失败再试 `hf-mirror.com`（`app/services/research/semantic/model-assets.js`）。
- 在设置"运行环境"页的"本地混合检索"一节，加"模型下载源"：
  - 官方（Hugging Face，默认，保持现有的失败后改试镜像）；
  - ModelScope；
  - HF 镜像；
  - 自定义地址。
  - 存设置，下载时使用。
- ModelScope 上要先确认有同一组文件；清单里的 SHA-256 校验保证文件一致，校验不通过就如实报错，不换源。
