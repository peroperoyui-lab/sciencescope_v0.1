## 5b 全局助手会话

参照旧版：`docs/SYSTEM_SPEC.md` §2.8（含 T17 跨项目查阅）、`desktop/assistant-chat.mjs`（秘书与助手共用的界面）、`docs/design/CONTEXT_ACCESS.md`。

- **助手就是参与者** `agent_assistant`。默认定义已有，设置页"全局助手"已能改提示词和模型。
- **会话**：全局只有一场助手会议，不属于任何项目，成员是用户和助手，历史一直保留。助手会议不出现在侧栏的项目与聊天树里。
- **跨项目查阅**（通过 5a 的上下文组装加入，不改 `turn-runner.js`）：
  - 每次发言前给一份工作区概览：最近的项目、各项目的纪要目标与待办、计划、导图要点、最近的会议。
  - 内容没变时不重复发送（旧版按变化哈希去重）。
  - 细节由助手用现有工具 `workspace_read`、`research_search` 下钻；工具已能按项目 id 读取，不新增按角色区分的工具（原则 2）。
  - 私有条目、临时会议不进入概览。
- **修改**：助手的修改和其他角色一样，直接生效并留下历史版本（原则 3）。
- **界面**（主窗口里，按旧结构复刻）：
  - 用户栏的"全局助手"按钮，打开助手面板。
  - 面板复用秘书栏的组件：消息流、输入框、模型与推理强度、停止、排队。助手面板和秘书栏共用一套组件，不复制代码。
  - 在助手面板里点到项目、会议或工作站时，主窗口跳到对应位置。
  - 隐藏面板时保留草稿，进行中的回答不停止。
- 秘书的"起草给主专家的指令"工具不变；助手不需要另做。

## 5c 原生助手窗口与浮球

- 原生外壳里已有旧版的助手窗口命令：`open_secondary_window`、`set_assistant_mode`、`get_assistant_mode`、`show_assistant_menu`、`hide_assistant`（`src-tauri/src/main.rs`）。
- 新核心模式下，这些命令目前只给 `main` 窗口授权（`capability["windows"] = ["main"]`），要把助手窗口和浮球加进去。
- **行为**：
  - 助手可以在独立窗口和浮球之间切换，可以隐藏；
  - 浮球置顶，不超出屏幕工作区；
  - 窗口尺寸记在数据目录。
- **启动设置**（设置"全局助手"页 P37 的"启动时"：关闭 / 浮球 / 展开）：存设置，原生外壳启动时读取。
- 浏览器里（非原生）只用 5b 的面板，不显示切换浮球的按钮。
