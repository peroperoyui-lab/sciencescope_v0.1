## 目标

让用户把自己的材料带进对话：
- 在输入框里附上文件和截图；
- 在右侧预览栏里阅读 PDF、DOCX 和代码；
- 在回答或文件里划选一段，加上备注作为"标记"，和下一条消息一起发给主专家、秘书或全局助手；
- 回答里的引用标签（如 `[S3 p.4]`）可以点击，打开原文对应的页。

行为以旧版为准：
- 规格：`docs/archive/legacy/SYSTEM_SPEC_2026-10-18.md` §2.4。
- 交互：`docs/design/INTERACTION_CONTRACTS.md` 2026-09-24 修订第 2 条（标记）。
- 旧代码：`desktop/research-input.mjs`、`file-preview.mjs`、`document-readers.mjs`、`research-citations.mjs`、`marks.css`，以及 `desktop/research-base.mjs` 末尾的"项目材料与引用"右栏。
- 旧后端：`scripts/research-input*.mjs`、`chat-attachments.mjs`。
- 原型页面：P08（文件预览与批注）、P46（本次上下文）。

实现按新核心写，不照搬旧的表和接口。

## 共同要求

- **附件就是资料库来源。** 附上的文件进入 R4-1 的资料库：项目会议进入项目材料，独立会议进入个人资料。原件存 `data/library/originals/`，不另建一套附件存储。
- **一套输入编译。** 主专家、秘书、全局助手、有序讨论的专家，用同一个编译方式把"正文 + 附件 + 标记"组成输入。放在 R4-5 拆出的上下文组装模块里，不改 `turn-runner.js`。
- **送给模型的格式沿用旧版。** 在 `[User-provided research material]` 段里放 `<material>`、`<quote>`、`<annotation>` 标签块；正文原样，属性转义。旧版做过对照实验（`scripts/evals/material-format-ab.mjs`），不要改格式。
- **不设上限（原则 4）。** 旧版的"文本附件共享 64000 字符预算""标记 16 / 32 条"都不搬过来。
  - 长文件不整份塞进输入，只给来源 id、文件名和页数。
  - 模型需要时用已有的 `research_read` 分页读取。
  - 这和旧版对 PDF / DOCX 的做法一致。
- **新状态用编号迁移建表**（012 起），不往消息 `refs` 里堆。
- **界面**：按旧结构一比一复刻，新文字补英文，不显示内部状态（`AGENTS.md` 原则 6）。

## 2a 附件与发送

- **添加附件**：输入框的加号菜单有"文件""截图""引用"三项；也可以拖入或粘贴文件。
  - 截图：原生里用系统截图后粘贴即可，不做截屏工具，只保证粘贴的图片能作为附件。
  - "引用"：从资料库选来源或条目，复用 R4-1 的检索接口。
- **附件条**：输入框上方显示附件条，点击附件可以"预览"（2b 接上）或"移除"。
- **草稿**：附件和标记随会议草稿保存，重启不丢。
- **发送**：
  - 正文、附件、标记一起组成这一轮的输入。
  - 发送后，消息下方显示回执"标记 N 条 · 材料 M 份"。
  - 发送失败时材料保留在输入框，不丢。
- **P46 本次上下文**：在消息菜单里打开。列出这条消息发出时实际带上的材料和标记，点击可以打开。
- **"项目材料与引用"右栏**（旧版右栏 `context`）：
  - 列出当前项目的来源和共享条目，可以搜索；
  - 勾选的项加入当前输入；
  - 不会自动发送。
- **范围**：秘书栏和全局助手面板的输入框也支持附件，它们本来就共用输入组件。

## 2b 文件预览与阅读器

- **右侧预览栏"文件预览与标记"**：
  - 可以从这些地方打开：附件条、资料库文献表的"预览"、材料详情、回答里的交付物卡片、项目文件夹。
  - 可以在当前项目的资料之间切换。
- **阅读器**（沿用旧版 T04 已验证的组件，依赖已在 `package.json` 的直接用）：
  - PDF：PDF.js，带文字层，支持跳页和高亮；
  - DOCX：正文阅读，只读版式；
  - Markdown / LaTeX / 代码：CodeMirror 只读，语法高亮；
  - CSV：表格。CSV 只显示前若干行属于"资源边界"，界面要写明"共 N 行，显示前 M 行"（原则 4 允许，但要说明省略了多少）。
  - 公式：用已接入的 KaTeX。
- **可点击的引用**：回答里的 `[S3 p.4]` 这类标签可以点击，打开预览栏并跳到对应页、高亮对应段落。未知的标签保持原文，不报错。复用 R4-1 的引用解析（`app/services/research/citations.js`）。
- 原件的读取接口要受本地口令保护，和现有接口一样。

## 2c 标记

- **划选标记**：
  - 在聊天消息或预览栏里划选文字，选区旁弹出小窗，可以写备注；Enter 添加，Shift+Enter 换行，Esc 关闭。
  - 不弹对话框，可以连续标记多处。
- **标记归属**：消息里的标记进入它所在会议的输入框（主对话 → 主输入框；秘书栏 → 秘书输入框；助手面板 → 助手输入框）。小窗里另有"引用至任务秘书""引用至全局助手""复制"。
- **"标记 N"按钮**：在附件条里，有标记时出现。点击展开二级窗口，按顺序列出：
  - 每个标记的来源：发言人，或文件名加页 / 段落；
  - 原文和备注。
  - 每条可以定位（滚动到原消息并闪烁，或打开预览并高亮）、改备注、移除；另有全部清除。
- **已有标记的显示**：预览栏中，已有的标记高亮显示。
- **发送后**：只清除这次发出去的标记；发送失败时恢复。
