- 起草：Claude，2026-10-25。依据：U5 完成（3676dff）；Yui 2026-10-25「可以，没什么问题，让codex干活吧」；U4 留下的「全新安装加服务商后真跑一次」。
- 执行：Sol（Windows）；审阅：Claude。约 2 小时，一步交付；超出就停下汇报。

## 目标

1. 确认 U5 的批注和索引在 Windows 桌面版里能用，docx 批注和 Word 来回不坏文件。
2. 补上 U4 没做的真跑：全新安装、加服务商后，专家改写和专家加批注、索引各一次。

## 用户会怎么用

- 在编辑台打开 docx，划选一句加批注、另一句加索引（索引指向项目里的数据文件），保存后用 Word 打开，批注在原来那几个字上；索引不进 Word。
- 在 Word 里改批注文字、再加一条批注，回到编辑台重新打开，两条都在侧栏里。
- 把标了批注的字全部删掉，底部提示「删掉的文字带走了 1 条批注」，Ctrl+Z 后文字和批注一起回来；删掉后保存，Word 打开不提示修复。

## 要做的

1. **Windows 全量检查**：干净检出 `npm ci` 后 `npm run check` 全部通过（含 Windows 测试和 `app/ui/desk.browser.test.js` 的 7 条）。
2. **Word 往返**（桌面版，用自己造的 docx，不用真实稿件）：
   - 上面三个场景各做一遍；另外试一条跨两段的 Word 原有批注：编辑台里能看到、不改它时保存后仍在。
   - 每次保存后用 Word 打开：不提示修复，批注范围和作者对，没有多出来的空批注。
   - md 文件里加批注、回复、标为已解决，重开编辑台后状态都在。
3. **原生窗口里的路径**：索引卡片上的来源，文件在预览里打开；消息来源点了以后主窗口跳到那条消息（编辑台是单独的原生窗口，这条只有桌面版能验）。右键菜单「查看索引」能亮起对应卡片。
4. **真跑**（全新安装到测试产品名下，设置里加 OpenCode Go，模型 `deepseek-v4.1-flash`）：
   - 选一句话，浮动工具条「润色」，专家改完出现提示条，「看改了什么」「撤销」都可用。
   - 在对话里请专家「给第三章里的样本数加一条索引，来源是 data 里的数据文件；对阈值那句提一条批注」，侧栏出现专家加的两条，作者是专家。
   - 报两次的请求数和 token。

发现的问题：后端或只在 Windows 出现的问题可以直接修（带测试）；界面上的问题只记下来，写清怎么复现，交给 Claude。
