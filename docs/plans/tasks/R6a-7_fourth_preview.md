## 要做的

1. **打正式包**：
   - 从 main 最新提交（提示里给 SHA）运行 `npm run package`。
   - 产品名、identifier、版本号（`1.0.0-alpha.0`）都不变。
   - 报告安装包大小、SHA-256、程序文件数和程序大小。和 R6a-6（13,254 个文件、372.11 MiB）以及 R6c 的目标（少于 3,000 个文件）对照，明显不同时写明原因。

2. **全新安装冒烟验收**：
   - 用 `SCIENCESCOPE_BUILD_VARIANT=installtest` 装到 `<测试安装目录>`。
   - 用 OpenCode Go 的 `deepseek-v4.1-flash`，材料用可以公开的自造材料。
   - 每一项通过或不通过都写下来，不通过的截图：
     - **首次启动**：首页一屏放下，插画、标题、问候居中，开头不错位。设置 →「关于 ScienceScope」能打开。
     - **服务商**：「模型与服务商」只填密钥添加 OpenCode Go，自动连接测试通过，报告这次请求的 model。
     - **项目资料**：新建项目，绑定一个放了一篇 PDF、一份 docx、一份 CSV 的测试文件夹。项目资料页里三个文件都显示已索引。
     - **主对话**：问一个和 PDF 有关的问题，回答带出处，下面有「本轮用到的资料」。
     - **编辑台**：
       - 打开那份 docx，改一句，Ctrl+S 写回；
       - 存一个版本，「审阅 → 比较」两版能并排显示；
       - 版本树里给分支改名后，节点上的分支标签跟着变。
     - **首页卡片**：离开这个项目回到首页，等秘书写完。首页显示这个项目的进度和四张卡片；点一张卡片，会在这个项目里开新对话，文字填进输入框。
     - **数据与备份**：「导出全部数据」能完成，打开导出文件夹能看到内容。
   - 关键画面截 100% 和 125% 各一套（需要时可以临时切到 100%，截完立刻恢复 125%，写明时间）。报告总请求数和 token。
   - 验收完卸载测试产品，并勾选删除数据。确认开始菜单和「应用和功能」里只剩用户那一份。

3. **覆盖安装到用户的预览目录**：
   - 关闭 ScienceScope，确认没有残留进程。
   - 把 `<预览安装目录>\data` 整个复制到**新目录** `<预览备份目录>\data`，核对文件数和总大小一致。以前的备份都不动。
   - 运行正式包，安装位置选 `<预览安装目录>`，覆盖安装，记下耗时。装完的程序文件数应等于全新安装。
   - 打开后核对：
     - 启动无报错。`data\logs\` 本次日志里，从上次安装以来的新迁移（到 032）都执行成功。
     - 原来的项目都在。
     - 「模型与服务商」里服务商还在，显示「密钥已保存」。点一次「测试连接」。
   - **不在用户数据里新建对话或项目，不发消息，不改设置。** 旧对话或旧版本打不开、显示异常时，照实截图报告，不要修（用户 2026-10-18：正式发布前旧数据可以不保留）。

4. **更新首测指南**：只改 `docs/handoff/PREVIEW_TEST.md` 第 1 节和第 2 节：
