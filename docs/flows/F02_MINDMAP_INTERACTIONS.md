# F02 · 研究框架与进展：完整交互规格

## 一张导图，两个使用场景

工作站展示同一项目导图的只读预览。用户可以平移、缩放、展开或收起、查看节点与文件引用。左上角的扩展按钮打开二级 GUI 编辑窗口。编辑窗口可以独立调整大小，关闭后回到原工作站位置；保存后工作站预览更新。

## 结构沿用 PPT

主干纵向排列，连接线表达研究内容之间的组织关系。右侧使用花括号组织二级内容，二级内容可以继续接更深层分支。主干和分支都可包含文字、Markdown、图片或文件引用。

PPT 的示例结构是绪论、综述、研究设计、实证分析。研究设计右侧包含数据来源和处理、理论基础、公式、本节参考文献、技术路线图。它是可自由编辑的结构，不是固定研究流程。

## 选择、编辑和定位

单击选中一个元素；双击、内容编辑按钮或右侧属性面板进入输入。方向移动和搜索可定位节点，定位时把目标移入画布可见范围。多选可用于移动、展开/收起或批量操作。拖动时给出目标层级和位置提示；上下按钮提供等价排序动作。

选中节点时，属性区展示内容、进展、图片、文件/说明引用及来源。节点文本内容本身可以是 Markdown；进展字段是可选的轻量标记。长正文保留完整内容，画布上可以折叠，编辑区可展开查看。

## 键盘行为

| 场景 | 按键 | 结果 |
|---|---|---|
| 主干输入框 | Enter | 在当前主干之后创建新的同级主干，焦点进入新框 |
| 花括号内输入框 | Enter | 在当前内容之后创建新的同级输入框，仍属于同一父节点 |
| 当前输入框 | Shift+Enter | 当前块内换行 |
| 选中元素或节点输入 | Tab | 添加子级并进入新输入框 |
| 普通文字编辑 | 常规选择、复制、粘贴、撤销 | 按文本编辑习惯工作 |
| 非文字编辑的画布 | Ctrl+Z / Ctrl+Shift+Z | 撤销/重做结构操作 |
| 编辑窗口 | Ctrl+S | 保存导图并更新预览 |
| 中文输入法组词中 | Enter | 先确认文字，保持当前输入框 |

## 加号与减号

- 没有子项的加号：创建第一个子级。
- 有子项、当前收起的加号：展开已有分支。
- 展开状态的减号：收起已有分支。
- 展开后继续添加同级内容：Enter 或右键“添加同级”。

以上按用户原文与图示作合理解释；原文减号被重复写成“展开”，本包将其统一为收起。预览区中的按钮只处理已有分支展开/收起；创建和编辑通过二级 GUI 完成。

## Markdown 和图片的三条插入路径

1. 在具体节点输入区右键 → 插入 Markdown/图片文件。
2. 将文件拖入具体节点或其输入框，目标高亮。
3. 复制文字、Markdown、图片或截图 → 在当前输入框粘贴。

三条路径都保持准确的目标节点。多文件按顺序插入；纯文本/Markdown 保留编辑能力，图片保存为该节点的附件引用。图片格式至少覆盖 PNG、JPEG、WebP、GIF、BMP，其他格式按实际读取能力呈现。

图片按原比例适配缩略图；最大宽度和高度可配置，本稿建议默认 280 × 180 px。点击缩略图放大查看，图片可替换、重新排序或移除；显示说明和原件位置。尺寸限制约束缩略图，不改变原图片像素和完整信息。

## 画布与窗口

滚动或拖动画布平移，Ctrl/Meta+滚轮围绕指针缩放；同时提供放大、缩小、实际比例和适应内容。预览和编辑窗口可以保持各自视角，内容保存共享。缩放不影响应用其他区域。花括号和连接线随内容和结构更新。

## 与秘书说明配合

用户、各级 Agent 和会议秘书都能管理导图，秘书承担日常整理。文献版本完成说明后，相关导图节点引用该 MD；节点又能打开对应版本、原件和项目摘要。手动编辑和 Agent 编辑均出现在项目修改记录。

用户正在编辑时出现其他更新，保留正在输入的内容，并提供查看新变化、采用或继续当前编辑的入口。保存、恢复和协作更新都清楚显示发生了什么。

## 导出与历史

支持可继续编辑的项目导图文件、Markdown 大纲和图片导出。图片附件和引用保持可定位。历史视图显示谁在什么时候更新了哪些节点以及关联来源，用户可以打开旧视图或恢复相关内容。

## 验收路径

从工作站进入编辑窗口 → 修改主干 → Enter 新建下一主干 → 在花括号中 Enter 增加同级框 → 使用三条路径插入 Markdown/图片 → 设置缩略图上限 → 展开/收起 → 排序与撤销 → 保存返回 → 工作站预览更新 → 查看关联版本说明。

另检查中文输入法、多图、超长 Markdown、删除后撤销、刷新后的已保存内容和用户编辑期间秘书更新。

原型已经实现节点选择、文本/Markdown 编辑、同级/子级、展开收起、上下移动、撤销重做、图片/Markdown 选择文件与拖放粘贴、缩略图、平移缩放、JSON/Markdown 导出及二级窗口保存同步代码。多选、自由拖动重排、全图查找、图片导出、磁盘协作更新属于本地开发需接通的完整功能，按本规格验收。
