# F04 · 计划、日志、修改记录与版本

## 信息层级

| 信息 | 范围 | 内容 |
|---|---|---|
| 计划 | 全局总览 | 下一步准备做的事，标题即可创建 |
| 项目日志 | 当前项目 | 关键节点与完成的重要工作 |
| 修改记录 | 当前项目 | 每次创建、修改、删除、重命名及操作者 |
| 文件/研究说明版本 | 具体对象 | 具体内容及前后差异、相关请求与批注 |

计划和日志分别编辑。切换项目时只有日志与项目内容切换。修改记录从置顶摘要展开，支持按一轮工作折叠，再到具体动作；创建后删除、修改后还原都能回看。

## 理论与文稿

理论变化用项目内研究说明承载，标明当前采用的表述、相关依据、讨论来源及待决定问题。文章段落、措辞和字词变化保存在稿件版本中，用户可看差异或打开原件。秘书整理关键变化，但用户与其他 Agent 都可管理。

意见先关联被评论的版本，真实编辑完成后关联新版本。只是解释或决定维持原文时，保存讨论结果即可。恢复旧版本后能继续查看原来的变化历史。

## 项目文件夹

文件树展示项目真实目录。点击文件交给默认程序；在资源管理器打开到对应目录。文件菜单还有预览、引用、重命名和加入版本管理。应用可管理的写入提供精确变化；外部程序改动按实际检测到的保存结果呈现，显示来源可确认程度。

## 摘要与上下文

秘书维护简洁项目总结：当前目标、采用方向、最新纠正、待决定项、相关材料。导图提供结构视角，版本说明提供本次更新视角。用户可以从摘要跳回它的依据，纠正摘要后继续工作。
