## 11a 窗口、历史版本、项目文件夹

### 1. Windows 窗口（L1 起就有，L1 验收只在默认尺寸截图，没有发现）

现象（用户实测，见截图）：
- 页面底部有一条约 61 逻辑像素的空白；
- 拖动窗口边框不能改变大小；
- 最大化或全屏后，页面仍是原来的大小，停在左上角；
- 文字和布局不跟随窗口变化。

界面样式用 `#app { height: 100vh }`，在 Linux 无头 Chromium 上能填满。最大化后页面不变，说明是 WebView 的大小没有跟随窗口，问题在原生外壳（`src-tauri`，`decorations: false`）。

- **先定位**：
  - 同一构建分别用旧宿主（不设 `SCIENCESCOPE_APP`）和新宿主启动，比较是否都有这个问题。
  - 在页面里记录 `innerWidth/innerHeight`，与 `getCurrentWindow().innerSize()` / `scaleFactor()` 对比，确认 WebView 是不是没有随窗口改变大小。
  - 检查 DPI 缩放（125% / 150%）下是否不同。
- **再修复**：
  - 无边框窗口要能从四边和四角拖动改变大小（Tauri v2 在 Windows 上的做法，或页面边缘的 `startResizeDragging`）。
  - 最大化、还原、全屏、改变缩放比例后，页面都填满窗口。
- **验收**：默认尺寸、拖大、拖小、最大化、还原、全屏，在 100% 和 125% 缩放下各截一张图。

### 2. 历史版本取代更改记录（`AGENTS.md` 原则 3 已改）

- **数据**：新迁移建 `resource_snapshots` 表。不叫 `versions`，避免和 R4-7 的文献（稿件）版本混淆。
  - 字段：资源、键、内容快照、作者（人或 AI 的参与者 id）、来源（离开页面 / AI 发言结束 / 恢复前）、时间、简短说明。
  - `revisions` 继续作为内部的细粒度记录（外部修改检测等仍需要），只是界面不再列出。
- **何时保留版本**：
  - 用户离开导图编辑窗口、计划页、日志页时，如果内容和上一个版本不同，保留一个版本；
  - AI 的一轮发言结束时，它改过的每个资源各保留一个版本；
  - 恢复旧版本之前，先把当前内容保留为一个版本，所以恢复本身也可以回退；
  - 用户手动编辑纪要时，也按同样规则保留版本。
  - 这项同时覆盖原计划在 alpha 之后做的"P48 导图历史"。
- **界面**：
  - 工作站左栏的"更改记录"改成"历史版本"。旧设计里左栏是"文献版本管理"，等 R4-7 做完再换回去，那时历史版本改由导图编辑窗口、计划页、日志页各自的"历史版本"按钮进入。所以这次就在这三处各放一个入口，左栏只是暂时的位置。
  - 历史版本列表：按导图 / 计划 / 日志分组，每条显示时间、作者、说明；可以查看（只读预览）、恢复到此版本、删除。删除前要确认。
  - 项目置顶摘要（P07）的"最近变更（可撤销）"改为最近的几个历史版本。
  - 导图编辑窗口里的撤销 / 重做只作用于这次打开的编辑，关闭窗口后清空。
- **AI 工具**：`workspace_undo` 保留，供 AI 在一轮里改正自己刚做的修改；另加 `workspace_versions`（列出、读取、恢复），所有角色共用。
- 文档：`CORE_MODEL.md` 写明版本与修订的关系，并更新 `docs/design/DATA_AND_ROLES.md` 里"修改即生效可撤销"的说法。

### 3. 项目文件夹

- 工作站的项目文件夹面板去掉整串路径，只显示文件夹内容和"打开 / 展开"按钮。
- 展开后的二级页面（P17）：
  - 已有：新建文件夹、重命名、添加文件。
  - 补上：删除文件或文件夹（移到系统回收站，不做永久删除；确认后执行）。

## 11b 对话与导图补齐（旧版有、新版缺，未列入其他任务）

参照旧文件：`desktop/main-outbox.mjs`、`desktop/deliverables.mjs`、`desktop/math-render.mjs`、`desktop/workbench.mjs`（导图部分）。

1. **回答进行中仍可发送（排队）**：
   - 主专家回答时，输入框仍显示"发送"，同时有"停止"。新消息进入排队列表，显示在输入框上方，可编辑或取消；当前回答结束后依次发送。
   - "停止"只停止当前回答，不清空排队；排队列表另有"全部取消"。
   - 排队存在会议上，重启后不丢。
2. **交付物**：
   - AI 在回答里展示的文件（图片、文档）显示在回答下方：图片显示缩略图，文档显示卡片，点击用默认程序打开。
   - 展示方式按 `docs/design/RUNTIME_PORT.md` 选择：用 DSH 的 `present`，或加一个 ScienceScope 自己的工具，选哪种写进文档。
   - 交付物进入其他参与者的上下文（只有路径和说明，`SYSTEM_SPEC` §2.5a 旧规则）。
3. **对话里的公式**：回答中的 `$…$`、`$$…$$` 用已经接入的 KaTeX 渲染，沿用旧版的净化规则（只有 KaTeX 生成的标记放宽）。
4. **导图**：
   - 游离节点：新增、移动。
   - 节点连线：添加、移除，可选有向；导图数据里已有 `edges`。
   - 粘贴或拖入 Markdown 文本成为节点内容（节点图片属于 R4-10，不做）。
   - 编辑提示沿用旧版："Enter 新建同级 · Shift+Enter 块内换行"。
