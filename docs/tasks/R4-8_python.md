## 目标

专家写的分析脚本能在一个受管的 Python 环境里直接运行：
- 应用自带 uv 管理的 CPython 3.14 和一个"内置 · 科学分析"环境；
- 项目和对话可以指定环境；
- 模型需要新包时，用工具直接安装；
- 用户在设置里管理环境。

行为以旧版为准：
- `docs/design/PYTHON_ENVIRONMENTS.md`（设计，含新建时的详情窗口）
- `docs/SYSTEM_SPEC.md` §2.20（T11 的实现与验证）
- 旧代码 `scripts/python-env/`（`uv.mjs`、`environments.mjs`）、`desktop/python-settings.mjs`、`desktop/creation-details.mjs`
- 包清单 `python/builtin.in`、`builtin.lock`、`builtin.json`（已在仓库，直接复用）

实现按新核心写，不照搬旧的表和接口。

## 和旧版不同的两处（按新原则）

1. **安装不审批**（原则 5；用户 2026-10-07 决定 R4-6 只做自动化，审批两档不做）：
   - `python_env_install` 直接执行，不弹审批卡片；
   - 会议里显示一张工具卡片：装了哪些包、原因、装进哪个环境、成功或失败；
   - 操作记录写明是谁、为什么装的。
   - 包名格式校验保留（只接受包名、extras 和版本约束）。这不是安全审批，而是 uv 的参数边界：URL、路径和命令行开关会让 uv 做别的事。
2. **数据位置**：
   - 环境、解释器、共享缓存放在新数据根下（新增 `dataPaths().python`），不放旧版的 `.sciencescope-local/python/`。
   - uv 可执行文件开发期放 `.sciencescope-local/runtimes/uv/`，或用 `SCIENCESCOPE_UV` 指定；打包时随安装包附带，属于 R6。

## 8a 环境服务与会话接入

- **服务** `app/services/python/`：
  - 封装 uv：不读用户的 uv / pip 配置（`UV_NO_CONFIG=1`、`PIP_CONFIG_FILE` 指向空设备），不碰系统 Python；
  - 首次需要时创建"内置 · 科学分析"环境，按 `builtin.lock` 安装；
  - 支持新建（选版本或从模板复制）、复制、重命名、删除、编辑包清单、导入导出 requirements.txt、清理未被引用的缓存、检测系统 Python；
  - 用户写的包清单和解析出的锁定版本分开保存；
  - 共享缓存用硬链接，跨分区时 uv 自动改为复制；
  - 统计占用空间时，独占部分和共享缓存分开算；
  - 失败的操作保留日志，界面显示失败原因（不显示原始日志，原则 6）。
- **数据**：新迁移（013 起）保存环境、包清单、锁定版本、项目 / 会议的绑定、操作记录。
- **解析顺序**：会议指定 → 项目指定 → "新任务默认环境"设置 → 系统 Python。选系统 Python 时不安装任何东西。
- **接到会话**：
  - 在运行时接口 `app/runtime/port.js` 的 `startSession` 增加一个可选的环境变量参数，DSH 适配器把它传给会话进程。
  - 变量只放宿主生成的白名单：环境的 `Scripts` / `bin` 放在 PATH 最前，加上 `VIRTUAL_ENV`。
  - 进程本身的环境和用户的系统环境都不改；密钥永远不进环境变量（原则 5）。
  - 从上下文组装模块取得本轮的环境，不改 `turn-runner.js` 的结构。
  - 专家与主专家用同一会议的环境；秘书和全局助手按各自会议解析。
- **切换环境**：
  - 空闲的会话下一轮重启生效；运行中的会话本轮结束后生效。
  - 会话 id 和历史保留（旧版已验证 DSH 能这样做）。
- **工具** `python_env_install { packages, reason, environment? }`：所有角色共用（原则 2）；默认装进当前会议解析出的环境。
- **提示**：在共用指令里加一句，说明需要新包时用 `python_env_install`，不要在终端里直接 `pip install`。

## 8b 设置页与选择入口（按旧结构复刻）

- **设置"运行环境"页的"Python 环境"一节**：
  - 环境列表：名称、Python 版本、包的数量、独占空间、被多少个项目或会议使用；
  - 操作：新建、复制、重命名、删除、编辑包清单（搜索、添加、移除、固定版本）、导入 / 导出；
  - 设置项：新任务默认环境、镜像源（官方、清华、阿里云、自定义）；
  - 共享缓存：总大小，清理未引用的包；
  - 系统 Python 的检测结果。
  - 删除仍有绑定的环境时，提示被哪些项目或会议使用，确认后把这些绑定改回默认（不报 409，用户 2026-10-07 起的思路是直接生效）。
- **新建项目页**：加"Python 环境"字段，默认"内置 · 科学分析"，可选其他环境或"系统 Python"。
- **独立对话的新建详情窗口**（`PYTHON_ENVIRONMENTS.md`"新建时的详情窗口"）：
  - 工作文件夹和 Python 环境两项；
  - 项目内新建的对话不弹窗，继承项目；
  - 临时提问不弹窗。
- **会议的工作区菜单**：加"Python 环境"小菜单，可以单独改这场会议的环境。
- **首次准备**：内置环境首次安装时，在设置页显示进度（下载中、完成、失败及原因），失败可以重试。进度用事件推送，不轮询。
