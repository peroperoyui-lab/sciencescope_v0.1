# R6a-5 覆盖安装清理旧文件，重新打包

- 起草：Claude，2026-10-17。依据：R6a-4 覆盖安装到 `<预览安装目录>` 后程序目录仍有 31,030 个文件（全新安装 9,697 个），旧版本的依赖文件没有删除；审阅补了「改用内置配置」（`63a5a09`），用户装的版本里还没有。
- 执行：Sol（Windows，本地 H 盘）；审阅：Claude。约 1–2 小时，一步交付；超出就停下汇报。

## 目标

覆盖安装时先删掉旧版本的程序文件，再装新文件；安装目录下的 `data\` 永远不动。用当前集成版本重新打包。

## 要做的

1. **安装前清理**：在 Tauri 的 NSIS 安装钩子（`NSIS_HOOK_PREINSTALL` 或等价做法）里删除上一版的程序文件：
   - 只删安装器自己装过的目录和文件（例如随包的 `runtime\`、`app\`、`node_modules\` 等，以实际布局为准）；`data\` 和用户在安装目录里自己放的其他文件不删。
   - 删除规则写成明确的列表，不用通配整个安装目录；在报告里列出这个列表。
   - 安装目录里没有旧版本时（全新安装）什么都不做。
2. **重新打包**：从集成分支最新提交打正式包，产品名、identifier、版本号不变。
3. **验收（只用测试产品）**：
   - 用 installtest 测试产品先装 R6a-4 的旧资源（或任意旧包），在 `data\` 里放一个标记文件，再用新包覆盖：程序文件数等于全新安装、标记文件和数据库都在，应用正常启动并能「测试连接」。
   - 记下覆盖安装耗时；验收完卸载测试产品并删除数据。
4. **用户的安装**：**先不要覆盖** `<预览安装目录>`。用户正在做第二轮首测，等用户或 Claude 说可以再装。新包放在 `.sciencescope-local\dist\`，报告大小和 SHA-256。

## 可以改的

`tools/package/`（含 NSIS 钩子文件和测试）、`docs/handoff/PREVIEW_TEST.md` 第 1 节、`docs/DESKTOP_IMPLEMENTATION.md`（不超过 5 行）。

## 不做的

- 不改 `app/`。
- 不改版本号，不签名，不做自动更新。
- 不动 `<预览安装目录>`、它的 `data\` 和备份目录。

## 完成标准

- 干净检出 `npm run check` 全部通过（含 2 项 Windows 测试）。
- 测试产品覆盖安装后文件数与全新安装一致，`data\` 完整。
- 报告不超过 15 行：远程分支与 SHA、删除列表、文件数、覆盖安装耗时、安装包 SHA-256。
