## 目标

让产品的核心在新核心上跑起来：用户在一场会议里可以
1. 在"工作"模式下用 `@专家名` 邀请某位专家回答（主专家本轮不答）；
2. 切到"有序讨论"，选几位专家并行回答同一问题，可选一位审核专家在他们全部完成后审核；审核结论经用户采纳才进入后续上下文。

行为以旧版为准：`docs/SYSTEM_SPEC.md` §2.5、`scripts/discussion-service.mjs`、`desktop/discussion.mjs`、`desktop/work-mode.mjs`。实现按新核心的模型写（`docs/design/CORE_MODEL.md` §6–§7），不照搬旧的子代理和 NDJSON 接口。

## 新核心里的做法（3a）

- **专家就是参与者。** 设置里的专家名册（`panel: 'expert' | 'reviewer'`、`enabled`、`position`）就是候选人。专家第一次在某场会议发言时，加入会议成员（`roleNote` 取其职责），之后出现在"在场的其他人"里。每位专家有自己的运行时会话，沿用现有上下文组装：第一次发言拿纪要 + 之后全部原文，之后只拿自上次发言以来的记录。不新建一套"专家上下文"。
- **发言规则存在会议上**（`meetings.policy_json`，§6 已有字段）：`{ mode: 'direct' }` 即"工作"；`{ mode: 'round', order: [专家 id…], reviewer: id | null }` 即"有序讨论"。模式和选择随会议保存，重启不丢（旧版只存在浏览器里，是已知限制，这次修掉）。
- **`direct` + @**：@ 的候选是会议里的 AI 成员加上已启用的参加专家（`panel: 'reviewer'` 不能被 @）。沿用 `mentionedParticipants`（长名优先）。
- **`round`**：用户发消息后，`order` 里的专家**并行**回答。每人的输入截止到这条用户消息，所以同一轮里看不到彼此。回答消息在开始时按 `order` 依次创建，界面按此顺序显示。
- **审核**：设了 `reviewer` 时，等本轮专家全部结束（不论成败）后再运行。输入是它的常规上下文加上本轮各专家的回答（标明作者）。审核消息 `adopted = false`，不进入任何人的后续上下文，直到用户采纳。审核没完成（失败、取消、输出上限）时不能采纳，接口返回 409。被采纳后，只要有任何后续发言已经读到它，就不能取消采纳（返回 409，说明原因）。
- **主专家补读**：不需要单独机制。主专家下次发言时，"自上次发言以来的记录"已包含专家回答和已采纳的审核。写测试确认。
- **停止**：`interrupt(meetingId)` 取消整轮，包括还没开始的审核。
- **重试和继续**：对某条专家回答，重试和继续只让这位专家再答，不重新触发整轮。现在"继续"是以用户名义发一条消息，在 `round` 模式下会触发整轮，需要改成定向。
- **上下文环**：每条专家回答所在发言（turn）的 `usage.context` 已经记录。接口能按会议列出每位专家最近一次的上下文占用，供 3b 使用。
- **并发**：同一会议内，一轮的多位专家可以并发；不同轮之间仍然排队。如果 DSH 适配在并发会话上有问题，在报告里写明，并用测试复现。
- 接口：沿用 `PATCH /api/meetings/:id`（改发言规则）和 `PATCH /api/messages/:id`（采纳）。只有确实缺少时才新增接口。专家回答的作者就是专家本人，所以消息接口返回的结果不用改。

## 界面（3b，按旧结构复刻，类名沿用旧样式表）

参照旧 `desktop/discussion.mjs`、`work-mode.mjs` 和对应的旧样式（`refresh.css` 的 `.discussion-strip`，`workspace.css` 的 `[data-v='mode-menu']`）：

- 输入框底部的协作方式菜单："工作 / 有序讨论"。读写会议的发言规则。
- 有序讨论条（输入框上方）：按名册顺序列出启用的参加专家，可点选本轮参加者；审核专家下拉框，包括参加专家和独立审核，可以选"无"。i 提示说明审核结论需采纳。
- 专家回答：显示真实作者名和职责；状态标签为 等待中 / 作答中 / 使用工具 / 已完成 / 未完成；工具卡片与主专家一致；回答是流式的。
- 审核结论上有"加入后续上下文"按钮；已采纳后显示状态，不能撤回时按钮失效并说明原因。
- 工作模式下输入 `@` 弹出候选菜单：↑↓ 选择，Enter/Tab 插入 `@名称 `，Esc 关闭，选择不会发送。
- 上下文环弹出层：同时列出本会议每位作答过的专家最近一次的占用。
- "停止"取消整轮。专家回答上的重试和继续只针对这位专家。
- 所有新文字在 `app/ui/i18n/en.js` 有英文。
