# T05 · 研究资料库界面：分类页、记忆收件箱、项目简报、引用标签

共同规则见 `docs/tasks/RB_COMMON.md`。后端接口见 `docs/design/RESEARCH_BASE.md` §6，全部已实现并有测试。

## 目标
把左侧"数据库"从文件列表改成按类别组织的研究资料库，并让用户看得见、管得了模型的长期记忆。保留原型的布局与导航（左侧栏入口、`content` 页结构、页签样式），不另起一套界面。

## 页面（`desktop/research-base.mjs` + `desktop/research-base.css`，取代 `desktop/library.mjs` 中的列表部分；旧的"详情 / 打开原件 / 预览"动作保留）
1. **文献与资料**：表格列为标签（S1…）、标题、作者、年份、期刊或来源、类型、解析状态、阅读状态、标签；支持筛选（类型、阅读状态、标签）、排序、分页（每页 50 条）。
   行内操作：预览（T04 阅读器）、打开原件、编辑元数据、重新解析。导入入口保留，导入后自动 `sources/ingest`。
2. **知识**、**模型与公式**、**主张与证据**、**记忆**：卡片列表加筛选（子类型、状态、置顶）。
   - 模型卡：用 KaTeX 显示 LaTeX，列出变量表（符号、含义、单位）、假设、步骤。
   - 主张卡：显示状态标签和证据数量；证据的完整界面由 T07 负责。
   - 记忆卡：按子类型分组（目标、决定、约定、偏好、未决问题、经验）；被取代的记录折叠显示，并链接到取代它的记录。
   - 每张卡都可以编辑（带 `expectedRevision`，冲突时提示刷新）、置顶、归档、取代（生成新版本）、查看修订历史。
3. **记忆收件箱**：待处理的提议，显示操作类型、内容、理由、来源（对话、角色、专家；点击来源跳转到对应消息）、证据；
   提供接受、修改后接受（在同一张卡上内联编辑）、拒绝，以及批量操作。左侧栏"数据库"入口旁用数字角标显示待处理数量。
4. **项目简报**：显示 `GET /api/research/brief` 的原文，也就是模型实际看到的内容，并提示字符预算；可以从这里跳到对应条目编辑。
5. **统一检索**：页面顶部的检索框调用 `/api/research/search`，结果按类型分组显示，并高亮片段。
