## 目标：1.0.0-alpha（内测版）
标准（摘自原计划）：每个核心功能都有**候选安装包**上的实测证据；程序退出后没有残留进程；升级后数据完整；卸载默认保留研究数据；签名可核查。
开发服务器上的测试、单项测试相加、改版本号，都不能代替上述验收。

### B · 安装、数据生命周期、签名与升级（未开始）
- Tauri NSIS 安装包：可选安装位置、快捷方式；应用自带 Node 运行时、uv 和 Python。
- 数据不随升级覆盖：数据库一致性备份、版本化迁移、文件迁移留有恢复记录；卸载默认保留研究数据。
- Tauri updater + GitHub Releases alpha 通道；首次发布前演练一次 alpha.1 → alpha.2 升级（不用唯一的用户数据库试验）。
- Windows Authenticode 签名与 updater 签名：**需要用户提供证书或签名服务**，在此之前签名验收保持 BLOCKED。
- 需要写明最低配置（见 `design/RESEARCH_BASE.md` §3.3），安装时检测。

### C · 候选包真实内测与上线门槛（未开始）
