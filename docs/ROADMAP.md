## 目标：1.0.0-alpha

在 Windows 上用候选安装包走完一次真实研究流程：导入资料 → 多位专家与用户讨论 → 秘书纪要 → 修改计划、导图、日志与文稿 → 退出、升级后数据完整。有安装包上的实测证据才算数，开发服务器上的测试不能代替。

## 主线

```
R0–R3 ✅ → L1 ✅ → R4 复原旧功能（M1 → M2）→ R5 旧数据导入、删除旧线 → R6 打包与升级 → alpha 候选 → 真实内测
```

原则不变：后端按 `design/CORE_MODEL.md` 重建；界面按旧主界面一比一复原（`design/UI_RESTORE.md`）；旧线只作参考，R5 删除。

## R5：切换

- 从旧数据目录导入：会话与消息、工作区文件（计划、导图、日志、纪要、笔记）、资料库（旧 `rb_*` 与原件）、设置与服务商（凭据只搬到 `data/secret/credentials.yaml`）。导入可重复执行，不改旧数据。
- 全部导出（已有项目快照 zip，补全量导出）。
- 原生外壳默认启动新核心；删除 `desktop/`、`scripts/`、`adapters/` 和旧宿主启动路径。

## R6：打包与升级（可与 R4 后半段并行，由 Dot 先在现有版本上演练）

- Windows NSIS 安装包，自带 Node 运行时、uv 与 Python；数据在安装目录 `data/`，升级不覆盖，卸载默认保留。
- 更新通道（GitHub Releases alpha）；首次发布前演练一次 alpha.1 → alpha.2 升级（Dot）。
- 签名需要用户提供证书或签名服务，到那时再做。
- 安装时检测并写明最低配置。

## alpha 之后（用户决定是否以及何时做）

- 旧版有、放到 alpha 之后的：R4-9 插件与技能（P41–P42、专家技能绑定）、R4-10 导图节点图片与附件（P16）。
- 新想法见 `idea.md`（写作工作台、WorkTeam、多模态嵌入）。
- 旧版没做完或本来就隐藏的：内置浏览器（P22 / P39）、用量分析（P35）、文献元数据查询与 BibTeX 互通（旧 T06）、主张–证据台账（旧 T07）、更改数据目录（旧 T16）、资料库图层与概念图谱（旧 T20）、扫描件 OCR。
