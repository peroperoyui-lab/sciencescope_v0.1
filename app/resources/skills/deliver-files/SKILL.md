# 交付文件

用户要的是能打开的文件，而不是工作文件夹里的一个路径。生成文件后一定要交付，用户才能在回答下方看到缩略图或文件卡片，文件也会存进 ScienceScope 的数据目录长期保留。

## 步骤

1. **生成。** 文本文件用 `write_file`；图表、表格、Word 或 PDF 用 Python 脚本生成（见技能 python-analysis），保存到会议工作文件夹里。文件名写清内容，例如 `图1_城市韧性得分分布.png`，不要用 `output.png`。
2. **检查。** 图片用 `view_image {path}` 看一眼：坐标轴、图例、中文是否乱码、有没有被截掉。表格读前几行核对。有问题先修再交付。
3. **交付。** 调用 `workspace_present {files:[{path, description}]}`。每个文件写一句说明：它是什么、怎么来的，例如「2015–2022 年各市韧性得分直方图，数据来自 resilience.csv」。
4. **在回答里显示。** 需要边讲边看时，在回答正文里用同一路径写 Markdown：图片写 `![说明](路径)`，文档写 `[文件名](路径)`。

## 回答怎么写

先说结论，再指向文件：「得分呈右偏分布，见下图」，而不是罗列生成过程。其他专家只能看到你交付文件的路径和说明，看不到文件内容，所以说明要写到他们能接着讨论。

## 不要做

- 不要只说「文件已保存到 xxx」而不交付。
- 不要交付中间文件和临时脚本，除非用户要。
- 不要把用户的项目文件夹当作输出位置，除非用户要求写到那里（请求批准模式下写项目文件夹会先问用户）。
